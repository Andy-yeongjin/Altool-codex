> **초기 구현의 역사 기록입니다.** 아래 수량·대표 브라우저 결과·미구현 목록은 회사 공통 팩과 UI 변형 확장 전의 관찰을 보존한 것입니다. 당시 미구현으로 기록한 목록 상세 복귀, 미디어/고급 검색, 다건 신청·내역, 정기 간행물 등의 UI 대안은 이후 구현으로 보완되었으므로 아래 문장을 현재 미구현 판정으로 재사용하지 않습니다. 최신 제공 변형·남은 경계·실제 검증 결과는 현재 manifest/mapping/contracts와 [COMPANY-VERIFICATION.md](COMPANY-VERIFICATION.md)를 확인하세요. 현재 QA 개발·검증 진행 상태이며, 이 초기 기록이나 게이트 H-1~H-4 승인만으로 정식 릴리스·전체 브라우저 검증 완료를 선언하지 않습니다.

검증일: 2026-09-08 (Asia/Seoul). 상태: **전 범위 색인·자산 연결 완료 / 대표 동작 검증 / 세부 규칙 전수 준수 미완료**.

## 자동 검사

프로젝트 루트에서 실행:

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/test_*.cjs
node designs/assets/ui-kit/internal/components/build.cjs --check
python3 altool/scripts/standards.py validate --root .
git diff --check
```

- Python87개, Node44개 통과. 기존 프로젝트 회귀도 포함한다.
- 컴포넌트 파생 파일53개·50구간 생성 결과 일치, standards 라우터 PASS.
- 자산 경로·ID, 모든 SVG의 카탈로그 등재·정적 XML, 988페이지 중복/누락 없음, 96구간 자산 존재, 공식 원본245파일 hash를 검사했다.
- 신규 설치 및 업데이트에서 기존 사용자 CI/카탈로그 보존, 디자인 TBD·base 프로필 유지, 자산 경로 외부 symlink 거부를 확인했다. 임시 설치 디렉터리에서 실행했으며 사용자의 앱에 실제 신청·변경을 보내지 않았다.
- 공식 원본을 변조한 채 일반 카탈로그 생성기를 실행하면 실패하며, 신뢰 manifest를 새 값으로 자동 승인하지 않는 회귀를 확인했다.
- 정적 HTML/JS 자산이므로 별도 프레임워크 번들 빌드·TypeScript 프로젝트는 없다. JS 구문 검사와 테스트를 브라우저 검사 전에 실행했다.

## 실제 브라우저 확인

Codex in-app Browser와 기존 `http://127.0.0.1:48765` 서버를 사용했다. DOM에서 대상을 확인한 뒤 실제 클릭·입력·선택·이동을 수행했다. 자동 테스트만으로 브라우저 결과를 대신하지 않았다.

### 카탈로그·이미지

- 데스크톱1280px: 분류9개 전환, 오류 문구 검색1건, 존재하지 않는 검색어0건과 안내, 초기화, CI·상태 이미지 렌더, 원문 대화상자 열기/닫기, 실제 메시지·파일 경로 클립보드 내용, 예제 새 탭 이동.
- 추가 스타일 필터에서 `palette-2024` 검색 → JSON 원문 → 경로 복사 확인. 콘솔 error 없음.
- 로딩 실패: `tests/fixtures/asset-load-error.html`에서 제품 JSON을 손상시키지 않고 실제 데이터 로드 실패 안내 확인. 이 테스트의 의도된404는 정상 서비스 오류로 집계하지 않는다.
- 초기390px iframe은 시각 점검만 했으며 모바일 조작 증거로 세지 않았다. 이후 실제 탭 `innerWidth=390`, `innerHeight=844`, 문서폭390을 확인하고 메시지 필터·검색·대화상자 열기/닫기·초기화를 직접 조작했다. 최종 대화상자 스크린샷에서 텍스트/닫기 버튼 잘림 없음. 모바일 실기기 인증은 아니다.
- 이미지 예제: SVG3개 정상 로딩, 정보/장식/기능 구분, 상세 설명 링크 클릭 → `#image-description` URL 및 실제 초점 이동 확인.

## 재검증에서 수정한 사항

1. 공식 원본 manifest를 일반 빌드가 재작성하던 문제: 고정 manifest 검증만 수행하도록 변경하고 변조 거부 회귀 추가.
2. 이미지 예제 SVG3개가 카탈로그에서 빠지던 문제: SVG 파생 자산 색인 및 모든 SVG 등재 회귀 추가.
3. 공식 캐러셀 wrapper의 Swiper 로딩 순서 수정 후74개 예제 로드 재검사.
4. 빈 첫 검색어와 OR 조건의 필터 결과 오류 수정 후 기본 패턴 회귀 통과.
5. 신청 임시 저장 후 시각 안내가 갱신되지 않는 문제: 성공 시 즉시 갱신, 실패 시 이전 안내 유지. 단위 실패 재현 후 실제 브라우저 재통과.
6. 신청 선택창 첫 옵션3개의 시작 태그 누락: 디지털 기초/온라인/오전 복구, 렌더 마크업·태그 짝 회귀 및 실제 선택 재통과.
7. 상세 탭 및 수평/모달 필터 대안 추가로 확인된 UI 대안 누락 보완.

## 남은 범위 — 완료로 승격하지 않은 항목

- **988쪽 모든 그림·문장·필수/권장/우수 강조·조건별 변형 전수 대조는 미완료.** 추출 텍스트에서 강조된 수준이 사라지므로 임의로 필수 수준을 지정하지 않았다.
- 실제 PDF 렌더 대조 범위는 `foundations/README.md`에 기록한 페이지와 아이콘 p.102–103, 기본 패턴 p.591 등 일부다. 원문 전체를 그림까지 재제작한 것은 아니다. 반례·기관 상징·실제 서비스 화면 캡처는 추천 CI/이미지로 복제하지 않았다.
- 공식 키트1.1.0과 PDF2024.02는 다른 버전이다. 74개 예제의 로드 성공은 모든 제어·변형·접근성의 동작 성공을 뜻하지 않는다.
- 목록→상세→목록의 일반 패턴 복원, 미디어 검색 특수 배치, 서비스 대상 다건 목록/대량 내역, 일부 고급 검색·정기 간행물 변형 등 미구현 대안은 `patterns/basic/mapping.json`과 `patterns/services/contracts.json`의 gaps에 남겼다.
- 실제 서버 인증·권한·동의·신청·검색 정확성·운영 데이터·법적 보존은 프로젝트별 구현이 필요하다. 이 팩의 모의 화면으로 대체할 수 없다.
- 스크린 리더, 모든 키보드 경로, 모바일 실기기, 고대비/확대의 모든 상태, 모든 네트워크 실패 변형은 미검증이다.

이 기록은 재사용 준비와 관찰 범위의 증거이며 정부 인증 또는 KRDS 전수 준수 보증서가 아니다.
