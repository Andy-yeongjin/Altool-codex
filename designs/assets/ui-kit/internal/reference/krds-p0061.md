스타일 가이드의 방향성
일관성 
(Consistency)
디자인 요소(색상, 서체, 형태, 배치, 아이콘)를 통해 공식 전자정부 
누리집으로서의 품질 유지와 신뢰도를 제고 할 수 있도록 일관성을 
유지할 수 있는 규칙과 제작 가이드를 제시한다.
공식 전자정부 누리집의 서비스를 이용하는 사용자 누구에게든 정보 
이용에 불편함이 없도록 W3C 웹 콘텐츠 접근성 지침*의 레벨 AA 
이상의 원칙을 기반으로 시각적 가이드를 제시한다.
* W3C 웹 콘텐츠 접근성 지침(WCAG) 참고
접근성 
(Accessibility)
정부 기관들의 다양한 개발 환경을 고려하여 커뮤니케이션 시간을 
절약할 수 있고 적용이 용이한 표준 규칙과 규격을 기반으로 
가이드를 제시한다.
효율성 
(Efficiency)
