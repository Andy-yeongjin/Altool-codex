# 상세 정보 확인

출처: 행정안전부, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.612–625. 공공누리 제1유형. [원문 참고](../../reference/krds-p0612.md).

## 재사용 범위

[실행 예제](detail.html)는 Altool이 독립 제작한 프런트엔드 조합 예제다. 공식 구현이나 접근성 인증이 아니며 실제 수집·제출·외부 API 호출은 하지 않는다. `basic.css`, `basic-core.js`, `basic.js`를 함께 사용하고 필요한 패턴의 초기화와 DOM만 선택한다. 고객 디자인 원본이 있으면 해당 시각 계약을 우선한다.

### 제공한 상태·변형

- 제목/요약/작성정보/변경표/단일 상세
- 우측 sticky 목차→모바일 상단 흐름
- 순서 도식·내부 링크·새 탭/다운로드 연결
- [탭 배치 대안](detail-tabs.html): 섹션 3개, roving tabindex, 방향키/Home/End 이동, 선택 패널만 표시

## 원문 적용 체크리스트

다음은 적용 프로젝트에서 확인할 목록이다. 항목 존재/자동 테스트를 전체 의미적 준수로 해석하지 않는다. 부적합 예제·실제 기관 브랜드·개인정보는 기본 자산으로 복제하지 않았다.

- [ ] BP-612-01: 상세 정보는 기본적으로 단일 화면에 제공하고 비교 불필요한 독립 내용일 때만 탭을 고려한다.
- [ ] BP-612-02: 제목·2~3줄 요약·상세/부가 정보·변경 이력·내부 목차·관련 액션을 구성한다.
- [ ] BP-612-03: 작성자·출처·저작권과 최초/변경 날짜·내용을 제목 근처 및 변경기록에 표시한다.
- [ ] BP-612-04: 제목과 계층을 구분하고 문장·문단은 간결하게, 핵심은 처음에 둔다.
- [ ] BP-612-05: 적절한 시각 자료는 내용을 보강하며 텍스트를 이미지로 바꾸지 않는다.
- [ ] BP-612-06: 외부/새 탭 액션은 이를 명시한다.
- [ ] BP-612-07: 넓은 화면 목차는 우측 고정, 좁은 화면에서는 제목과 본문 사이에 흐름 배치한다.
- [ ] BP-612-08: 텍스트 명도 대비·비텍스트 대체수단·구조화된 제목/목록/표를 제공한다.
- [ ] BP-612-09: 멀티미디어가 있으면 키보드 조작과 자막/대본/대체 설명을 제공하고 자동 재생하지 않는다.

## 실제 브라우저 재검증 시나리오

1. 목차4개 클릭 → 각 section과 URL해시
2. 목록 example 쿼리로 진입 → 선택한 제목 표시
3. 390/1280 목차위치, 새탭 도움말/첨부파일 페이지 이동
4. 탭 대안에서 추가 도움/변경 내역/이용 방법을 클릭하고 ArrowLeft/ArrowRight/Home/End로 이동한다. 선택 탭 1개와 표시 패널 1개, 현재 탭의 tabindex=0을 확인한다.
5. 390px/1280px에서 잘림·겹침·포커스·주요 동작·콘솔 오류를 확인한다. 키보드와 실제 스크린리더 확인은 별도이며 정적 마크업 검사로 대체하지 않는다.

## 미적용·잔여 검증

- 탭 변형은 별도 페이지로 제공한다. 비교가 필요한 본문을 임의로 분할하지 말고 성격이 다른 부가 정보에만 적용한다.
- 이미지·영상·오디오·자막·대본 연결 UI는 `content-variants.html#media-player`에 제공한다. 권리가 있는 실제 미디어 파일과 자막·대본의 내용 정확성 검증은 실제 서비스 자료를 대상으로 수행한다.
- 실제 정책 내용·작성권한·콘텐츠 CMS/변경 이력 저장은 구현하지 않았다.
- 이 파일 작성 시 실제 브라우저 조작 검증은 부모 작업에 인계했다. 자동 규칙/마크업 검사 결과는 `README.md`의 검증 명령과 별도 작업 보고를 확인한다.
