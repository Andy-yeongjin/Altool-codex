# 공통 UI 변형·상태 인벤토리

`variants-manifest.json`은 11개 의미 ID 아래 75개 변형을 구분한다. `path`와 `dependencies`는 `designs/assets/` 기준, `selector`는 실행 문서의 대상 구획, `states`는 제공되는 UI 상태, `sourcePages`는 2024.02 KRDS 기본 패턴의 해당 항목이다. 같은 화면에서 선택 컨트롤로 전환하는 상태도 별도 변형으로 색인한다. 이것은 75개의 독립 앱이나 실제 업무 API를 의미하지 않는다.

## 추가 구현과 실제 브라우저 시나리오

### 목록·필터 복귀

- `list.html`: 검색어 `안내`, 표 또는 아코디언 보기, 2페이지로 이동한다. 아코디언이면 한 항목을 연다. 목록 아래쪽 상세 링크를 열고 상세의 **이전 목록으로 돌아가기**를 누른다. 검색어·보기·페이지·열린 아코디언·스크롤·해당 링크 초점이 복원되는지 확인한다.
- `filter.html`: 교육 분야 적용, 오래된순 적용, 2페이지 상세를 연 뒤 돌아온다. 적용 조건·정렬·결과·페이지·즉각/일괄 표시·스크롤·링크 초점을 확인한다.
- `filter-layouts.html`: 모달 배치에서 조건 적용 후 상세를 열고 돌아온다. 모달 배치·적용 조건·페이지·스크롤·초점을 확인한다. 모달을 다시 열면 적용했던 조건이 표시되어야 한다.
- 탐색 상태만 URL fragment에 보존한다. 이름·생년월일·전화번호·동의·평가·입력폼 값은 기록하지 않는다. 기록된 주소를 공유하면 비민감 검색 조건도 함께 공유될 수 있으므로 실제 앱에서 개인정보 검색을 허용한다면 서버/세션 내 별도 보호된 상태 저장 경계를 설계한다.
- 외부 URL이나 허용하지 않은 반환 경로는 수용하지 않는다. 상세를 직접 열면 기본 목록 링크가 제공된다.

### 입력·동의 (`field-variants.html`)

1. 생년월일 2024/2/30 → 오류·첫 필드 초점·값 유지. 2024/2/29 → 확인.
2. 체크박스 전체 동의 → 두 항목 선택. 선택 동의 해제 → 일괄 부분 상태, 필수만 동의해도 진행 가능. 필수 해제 후 제출 → 오류.
3. 필수 표시를 텍스트·별표·모두 필수로 변경한다. 레이블·설명·required가 같이 변경되는지 확인한다.
4. 액션 왼쪽/오른쪽 변경 → 주 액션 순서와 3차 액션 위치를 확인한다.
5. 미완성 비활성화 선택 → 빈 입력 제출 disabled. `abc-01`과 필요한 설명을 입력 → enabled. `A!` → 실시간 오류. 작성 취소 → 필드 초기화와 상태 복원.

### 도움·피드백 (`content-variants.html`)

1. 작성/검토 주제, 패널/코치마크 표시를 각각 선택해 3단계 이전·다음·마치기·그만보기·진행률·대상 강조 해제를 확인한다.
2. 제목과 본문에 가상 내용을 입력하고 미리보기를 누른다. 문자 내용이 HTML로 실행되지 않고 텍스트로 표시되는지 확인한다.
3. 이용 전에는 피드백이 숨겨져 있어야 한다. 자료 이용 완료 → 추가 질문 없는 평가 → 즉시 완료 메시지. 되돌리기 → 이용 전 상태.
4. 넓은 화면 사이드/하단 배치를 선택한다. 좁은 화면에서는 사이드 선택도 본문 아래에 표시되어야 한다.

### 미디어 (`content-variants.html`)

1. 설명 없이 파일 선택 → 설명 요청. 설명 입력 후 보유 권리가 있는 이미지 선택 → 이미지·alt. 연결 제거 → 빈 상태.
2. 영상/오디오 유형 변경 → 이전 파일 정지·object URL 해제·기본 빈 상태. 파일 선택 → 자동 재생되지 않음. 네이티브 컨트롤로 재생·정지·음량·시간을 키보드로 확인한다.
3. 영상 로드 뒤 `.vtt` 자막 파일을 연결한다. 형식/크기 오류, 자막 메뉴, 대본 편집/펼침을 확인한다. 삭제 중 읽기 완료된 오래된 자막은 다시 연결되지 않아야 한다.
4. 자료 형식이 지원되지 않으면 오류 메시지가 표시되어야 한다. 실제 콘텐츠의 자막·대본·음성 해설 정확성, DRM/코덱 지원은 실제 자료를 사용하여 검증한다.

미디어 플레이어·이미지·자막·대본의 **재사용 UI는 구현되어 있다**. 사용 권한이 확인된 실제 사진/영상/음성 파일을 이 제작 작업이 대신 제공하지는 않는다.

### 요청 상태·범위 (`state-variants.html`)

1. 성공 결과 선택 → 요청 실행 → loading/중복 실행 disabled → 완료. 값은 유지된다.
2. 연결 오류 선택 → 실행 → alert/재시도. 다음 결과를 성공으로 변경하고 다시 시도 → 성공.
3. 결과 없음 → 빈 상태와 조건 수정 안내. 요청 실행 직후 취소 → idle·입력 보존·시작 버튼 초점, 늦은 완료 메시지가 나타나지 않아야 한다.
4. 최소/최대 숫자와 슬라이더를 서로 변경해 동기화한다. 범위 역순은 오류. 분야 두 개 선택은 합집합, 미선택은 전체. 적용 결과·빈 결과·초기화를 확인한다.

## 원문 그림 재대조 보완

`precision-variants.html`은 긴 모바일 목차 접기, 연월 전체를 포함하는 범위, 하루 중 시간 범위를 제공한다. 같은 달 조회, 역순 오류 시 값·이전 결과 유지, 빈 결과, 10개 페이지와 초기화를 포함한다. 75개 변형 가운데 이번에 보완한 3개이며, 실제 실행 검증표는 `FINAL-BROWSER-SCENARIOS.md`, 페이지별 원문 열람은 `final-source-review.json`을 본다. 질문 없는 평가 완료에서도 선택 버튼이 사라지지 않고 초점을 유지한다.

## 실제 업무가 소유하는 경계

- 실제 사용자 식별·권한·개명 정보·국가별 전화번호 검증, 법적 약관 내용과 증거 보관
- 실제 서버 검색 인덱스·권한별 데이터·서버 검증·저장/복구·중복 요청 방지
- 실제 피드백 전송/분석, 네트워크 오류 분류/진단, 실제 삭제/이탈 보호
- 실제 미디어 파일의 권리·전사/자막 정확성·코덱 호환

위 경계는 UI 미구현을 뜻하지 않는다. UI 전환과 사용자가 보는 복구 수단은 로컬 어댑터로 제공하고, 실행 환경의 API에 연결할 때 해당 계약과 테스트를 추가한다. 자동 검사나 그림 참고만으로 실제 브라우저·스크린리더·법적 적합성을 인증하지 않는다.
