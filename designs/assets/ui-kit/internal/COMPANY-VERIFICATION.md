## 통일성을 위한 변경

1. `standards/design.md#assets`에서 채택 자산 우선 탐색·필수 재사용을 지정했다. 헌법의 사용자 디자인 우선순위가 회사 의미 자산을 임의로 바꾸는 근거가 되지 않도록 정렬했다. 전체 PDF를 매번 읽는 대신 ID를 resolve하여 해당 파일·의존성만 읽는다.
2. 같은 아이콘·문구를 두 독립 클라이언트가 동일 ID로 요청하는 런타임을 제공했다. 미등록 ID/변형과 변조된 registry/요청 바이트는 거부한다.
3. UI 작업은 사용 파일·ID·변형·복사본 및 기능 전용 근거를 기록한다. 게이트는 소비 파일 해시까지 묶어 오래된 증거를 거부한다. `oneshot` 자식 단계에도 연결했다. 문자열 참조만으로 실행 경로·모든 UI 의미를 증명하지는 않으므로 Analyze/Browser 대조가 필요하다.
4. 기존 정상 설치 팩은 유지하고 충돌·손상은 자산 배치 전에 거부한다. 회사는 같은 제작 원본의 같은 release/lock을 여러 프로젝트에 배포해야 한다. 자동 교차 저장소 동기화나 중앙 배포 서버는 포함하지 않는다.
5. 회사용 헤더·푸터는 정부 표시 없는 중립 자산으로 제공한다. 샘플 CI는 실제 회사 CI 확정이 아니다.
6. 공식 CSS 원본을 보존하며 공통 어댑터에서 16px 루트·2024 토큰을 정렬했다. 원본 10px 루트 CSS와 authored 16px UI를 섞어 글자가 줄어드는 문제를 방지했다.
7. 일반 업로드/파일 크기·개수·형식/날짜/오류/이미지 로드 문구는 `messages/ko.json`에서 생성한다. 구체적인 호스트 실패 원인은 별도 설명이며 일반 메시지를 덮어쓰지 않는다.

## QA5 당시 남은 검증과 적용 경계

- 식별된 재사용 변형은 manifest에 제작·연결했다. **988쪽의 모든 그림·강조·조건을 시각적으로 전수 대조해 추가 누락이 없다고 확정한 상태는 아니다.** 기존에 미구현이었던 목록 복원/고급 검색/미디어/다건 신청/대량 내역/간행물 UI는 이번에 구현했으므로 백엔드 미구현과 섞지 않는다.
- 모든94+72+13변형의 주요 제어·키보드·고대비·확대·스크린리더·모바일 실기기·모든 미디어 조합은 미검증이다. 따라서 전수 검증 완료나 KRDS 공식 인증을 주장하지 않는다.
- 실제 서버, 권한, 회사 CI 확정, 업무 콘텐츠, 법적 약관·동의 보관, 운영 데이터는 소비 프로젝트가 연결한다. 같은 회사는 같은 release/lock을 배포해야 하며 서로 다른 팩을 쓰는 앱까지 자동으로 통일되지는 않는다.

추가 작업 결과는 자산 선제작·필수 재사용·변경 탐지의 구현이다. 남은 검증이 있으므로 정식 릴리스로 승격하지 않았고 이번 요청에서 git 커밋/푸시는 하지 않았다.
