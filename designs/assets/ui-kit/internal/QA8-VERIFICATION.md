## 자동 검사

- 전체 Python128개 PASS,전체 Node123개 PASS. Python 일부가 Node를 호출하므로 독립 총합으로 더하지 않는다.

- `scripts/build_source_review.py --verify-renders`: 실제 관찰988/988·4장부 SHA·모든 렌더 SHA PASS.
- `standards.py validate --root .`, `assets.py validate`, `git diff --check` PASS. macOS 새 설치/보존 회귀 포함. Windows 실기기 실행 없음.

## 적용 경계

원문 열람·식별 자산 제작과 위 대표 검증은 완료했다.320변형의 모든 상태 조합·브라우저/실기기·스크린리더·강제 고대비·확대율·모든 코덱을 전수 인증하지 않았다. 조건부 단일 슬라이드·정교한 파일 드롭/다운로드 저장·서비스 연동 분기는 해당 호스트에서 검증한다. 원문의 모든 문장/반례를 하나의 PASS로 승격하지 않는다.

회사 CI·승인 문구·실데이터·API/권한·서버 저장·법적 동의·업무 콘텐츠는 도입/소비 프로젝트 입력이다. 공통 UI 제작 미완료와 구분한다. 설치용 `standards/design.md` TBD도 유지한다. 범위가 정해진 상품 Spec/QA를 고객 디자인 완료나 Altool run/Step Check 완료로 위장하지 않았다. QA6 데모 usage는 과거 기록으로 남기고 이번 관찰/파일 해시는 `QA8-OBSERVATIONS.json`에 별도로 묶는다.

기존 설치본 마이그레이션·실제 회사 적용·git 커밋/푸시는 이번 작업에서 하지 않았다.
