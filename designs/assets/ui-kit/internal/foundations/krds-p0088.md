# 04. 배치(Layout) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.88-100. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 그리드·화면마진·칼럼·거터·콘텐츠최대폭·주요영역간격을 별개로 정의한다.
- [ ] 360/390/600/601/768/1024/1025/1440 너비에서 경계와 재배치를 확인한다. 360보다 좁은 화면도 무조건 잘라내지 않는다.
- [ ] 모바일 칼럼 대안의 p90/p94 불일치는 기본4열로 해결하고 다른 선택은 기록한다. 8px 단위와 허용4px 보조단위를 구분한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.
