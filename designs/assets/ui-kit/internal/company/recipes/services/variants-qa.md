# 서비스 변형 브라우저 검증

아래 목록은 시나리오 정의이며 이전 디자인의 실행 기록을 현재 v27 화면의 검증 통과로 사용하지 않는다. 현재 실브라우저 검증은 접근 정책 차단으로 미완료다.

공통 전제: 회사 팩 레지스트리·해시를 최신 파일로 생성한 뒤 로컬 HTTP의 `variants.html` 사용. 실제 개인정보·계정·신청 금지. 담당 부모가 인앱 브라우저로 데스크톱/모바일을 검증하며 아래 목록 자체는 통과 증거가 아니다.

1. 각 상단 메뉴에서 로딩→빈 상태→오류→공통 재시도→정상 전환. 회사 오류 문구와 재시도 버튼이 런타임에서 표시되고 필터는 유지되는지 확인. 각 정상 화면의 URL·title·콘솔·넘침 확인.
2. 홈: 중요 안내 숨기기/표시, 이전/다음3개 슬라이드, 자동전환 시작 후 변경·정지 후 유지, 목적별 탭 클릭/좌우키, 모의 개인화 전환.
3. 검색: 빈 검색18건·10/8 페이지, 문서/이미지/영상 유형, 고급검색 열기→AND `디지털`/OR `배움 안전`/NOT `13` 적용. 시작>종료 오류에서 모달이 닫히지 않는지 확인. 취소는 이전 조건 보존. 없는 단어0건·조건 해제. 느린검색 진행률→중단/다시실행→완료. 교정 제안 사용.
4. 미디어: 이미지 결과→확대·축소·초기화·저장. 영상 결과→12초 설명 재생·정지·시간탐색·자막전환·처음. 개인정보 없는 로컬 MP4/WebM 선택→기본 비디오 재생/중지; 잘못된 파일·미디어 디코딩 오류 안내. 모달 닫은 후 재생 정지. 문서 새창은 같은 로컬 예제이고 다운로드는 명시된 샘플인지 확인.
5. 인증: 안내3유형 열기·취소·로그인 안 함·이동; 개인/기관 탭과16개 방식. 단일/단계/집중형 각각 선택→다음/이전→빈값/잘못된 확인번호→예제 `000000` 성공. 기억 체크→다시 선택에 마지막 방식 표시. 계정복구 도움. 자동복귀 체크/해제의 서로 다른 결과. 아무 키 연장 선택 변형의 모의 세션 표시.
6. 서비스: 목록24건·페이지 이동·접수상태4종·신청유형4종·이름/신청가능순, 2개 선택→다음페이지 선택→모아보기→해제. 상세 기본/부가 탭과 키보드→목록 복귀 필터/스크롤 보존. 예정/마감은 신청불가, 외부는 로컬새창. 가능한 서비스 바로신청.
7. 신청: 제출 주체·조회 `DEMO-2024`·발급 문서유형·예약 날짜/시간을 각각 빈값부터 검증. 공동확인 체크→동의 미체크 오류→동의 후 오류 제거. 직접첨부 전환→정상·잘못된 확장자·5MB초과→제거. 확인 화면/모달의 돌아가기 값보존, 반복발급 예외는 발급일 때만 생략. 확정→번호·모의완료→내역 동일번호, 발급 TXT 내용. 같은유형 다시진행.
8. 내역: 37건+신규, 날짜/상태/정렬/역전기간 오류·0건, 페이지1 선택→2페이지 추가선택→전체선택/해제, 선택 TXT, 취소가능/불가혼합→확인취소/확정, 보완요청→검토중, 상세 현재단계, 인쇄 미리보기 후 취소. 새로고침시 고정37건으로 복원.
9. 자료: 유형3종·상태6종·기간·역전기간·검색·0건·페이지·상세닫기; 신규/변경·일시중단/발행종료/주기변경 안내를 각각 확인. 변경이력·도해·자료저장·관련신청 링크 확인.

## 최종 원문 대조 이후 추가 조작

아래는 아직 부모 브라우저 실행을 기다리는 체크표이며 완료 표시는 아니다.

| 페이지/대상 | 조작 | 기대 결과 |
| --- | --- | --- |
| 모든 페이지 헤더 | 전체 자료 검색 입력→Enter, 검색창 열기→Escape/닫기/검색 실행 | 결과의 검색어 유지, 레이어 닫기 시 초점/맥락 보존 |
| `#search` | 빈값 검색, 분류별 버튼, 관련도/최신/인기,10/20,가로/측면 | 전체18·유형별6, 조건별 건수, 선택/정렬/페이지 변경, 모바일 넘침 없음 |
| `#search` | `디지털` 검색→하이라이트, 고급 조건 적용/취소, 진행률 중 필터 변경 | 문자열 안전한 강조, 조건 보존, 떠난 화면의 타이머 오류 없음 |
| 영상 미리보기 | 실제 WebM 재생·정지·9초 탐색·한국어 자막·오류 재현·재시도·닫기 | 12초 영상/3단계 강조/해당 자막, 오류 대안·복구, 닫으면 정지 |
| `#services/detail/S3`→로그인 | 자동복귀 체크→방식 선택→000000 | 정확한S3해시, 모의 로그인 헤더·내역 메뉴, 로그아웃 후 홈 |
| `#services/transaction` | 예약빈값 제출→날짜만→시간→공동확인 동의 누락→동의후확정 | 각각 첫 오류 필드 포커스·aria-invalid, 성공 때 이전 오류 소멸 |
| 신규 내역 상세 | 위 예약 또는 파일첨부 제출 완료→내역 상세 | 해당 유형의 모든값·증빙/동의·파일명/크기, 관련 없는 이전 유형값 없음 |

과거 원문 대조 장부는 배포에서 제거했으며 참고출처는 [출처 기록](../../../ATTRIBUTION.md)에 남긴다. 실제 스크린 리더, 모든 조건 조합, 실제 서버는 별도 증거가 필요하다. 반례는 추천 화면으로 복제하지 않는다.
