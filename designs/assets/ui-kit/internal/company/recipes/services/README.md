# v27 회사 레시피 이식

공통 외형은 `../../dist/company.css`, 추가 조합 레이아웃은 `../recipes.css`만 사용한다. 기존 정부 디자인 CSS·이미지·폰트는 의존하지 않는다. 절차 SVG와 영상은 v27 팔레트로 새로 제작했다. 모델·상태 전이만 이전 독립 제작 코드에서 이식했다. 원본 PDF·추출 문서·과거 원문 대조 장부는 배포에서 제거하고 출처 표시만 남긴다. 실브라우저 검증은 접근 정책 차단으로 미완료다.

# 회사 서비스 패턴 자산

**범위:** 원 PDF p.686–978의 서비스 패턴 5개군, 개요 5개 + 단계 25개 = 30개 목차 항목.
**결과:** 재사용 가능한 로컬 다단계 화면, 단계별 동작, 상태·변형 목록. **모든 적용 조건·서버 기능·원문 시각 사례를 완전 구현/검증했다는 뜻이 아니다.**

출처: 행정안전부, 「디지털 정부서비스 UI/UX 가이드라인」(2024.02), 공공누리 제1유형 출처 표시. 참고출처와 권리는 [출처 기록](../../../ATTRIBUTION.md)을 따른다. 예제 화면·문구·가상 데이터·프로그램은 Altool이 새로 작성했고 원문 기관 로고·인물·개인정보·사례 스크린샷은 복제하지 않는다. 정부에서 이 구현을 인증·보증했다는 의미가 아니다.

## 사용

기존 로컬 HTTP 미리보기에서 [기본 서비스 실습실](index.html) 또는 [서비스 유형·상태 변형](variants.html)을 연다. HTML/CSS/JavaScript만 사용하며 외부 라이브러리·CDN·외부 API는 사용하지 않는다. 확장 화면의 공통 오류는 같은 설치본의 회사 자산 런타임·레지스트리·문구를 로컬 HTTP로 읽는다. 파일을 따로 복사하지 말고 `variants-manifest.json`의 실행 파일·의존성과 공통 팩을 함께 설치한다.

색상·간격·서체·모서리는 `../../dist/company.css`가 원천이다. 서비스 CSS는 이를 참조하며 로그인·검색 아이콘은 v27 Lucide 자산을 사용한다. 기관별 디자인 표준 TBD를 이 샘플만으로 확정 처리하지 않는다.

| 흐름 | 실행 진입점 | 실제 제공 |
| --- | --- | --- |
| 방문 | [홈](index.html#visit) | 목적별 탐색, 중요 안내, 모의 개인화 진입 |

| 로그인 | [모의 로그인](index.html#login) | 안내 모달·방식 비교·예제 양식·오류·완료·30초 만료 안내·연장·로그아웃 |

## 책임 경계와 저장

- 로그인은 메모리의 `signedIn` 표시일 뿐 인증 코드가 아니다. 계정·비밀번호를 저장하거나 전송하지 않는다. 예제 `demo@example.invalid / sample-only` 또는 무입력 대체 흐름만 사용한다. 실무에서는 인증·권한·세션 검증을 서버 경계에서 구현한다.
- 기본 신청은 브라우저 내 연습 기록이다. 자격·교육 주제·참여 방법·시간대의 허용된 고정 선택값만 저장한다. `localStorage` 키는 `altool.krds2024.service-demo.v1` 하나다. 저장소 접근 실패는 화면에서 알린다. 확장 신청의 파일 선택은 테스트 파일명·크기만 탭에 표시하며 내용은 읽거나 전송하지 않는다. 실제 개인정보 파일은 사용하지 않는다.
- 새로고침 보존: 명시적으로 임시 저장한 양식, 모의 접수·취소 내역. 새로고침 초기화: 모의 로그인, 검색 조건·최근 검색어, 관심 정책. 현재 탭에서 상세/목록 이동 시 검색·정책 조건과 작성 중 선택값은 유지한다.
- 신청 내역 하단의 삭제 버튼은 이 예제의 키만, 확인 후 지운다. 임시 저장·내역을 실제 민원/정책 데이터처럼 다루지 않는다.
- 예제 정책 데이터 기준일은 **2024-02-29**다. 최신 정부정책·법률 안내가 아니다. 검색 기간 옵션도 이 고정 날짜 기준이다.
- 기본 로그인은 완료 화면에서 **이전 과업 계속하기**를 누른다. 확장 로그인에는 이전 과업 자동복귀 선택 변형도 있다. 실제 SSO·권한·외부 리디렉션은 별도 서버 연결 영역이다.

확장 화면 상단의 상태 선택으로 각 화면의 로딩·빈 상태·오류·재시도를 실제 전환한다. 확장 상태·신청·선택은 탭 메모리만 사용하며 새로고침하면 초기화된다. 직접 만든 신청의 내역 상세에는 해당 유형의 모든 입력값과 모의 증빙/동의 선택이 보존된다. 기존37건은 목록·상태용 가상 데이터이며 제출 양식은 없다.

미디어는 자체 제작한 12초 무음 `process-demo.webm`(640×360 VP9), 한국어 `process-demo.ko.vtt`, 텍스트 대본, 재생/정지/탐색과 오류/복구를 제공한다. 기존 HTML 절차 애니메이션은 별도 제어 예제다. 선택한 로컬 MP4/WebM(50MB 이하)은 브라우저에서만 재생하며 외부 업로드가 없다. 운영 회사 영상·자막·저작권은 별도 연결한다. 원본 프레임 생성기는 `render-process-video.swift`이며 macOS AppKit과 FFmpeg로 모의 절차 도해를 생성했다.

검색 변형은 헤더 인라인 입력/검색 레이어, 관련도 기본·최신·모의 인기, 분류별 건수·검색어 강조, 10/20개 결과, 가로/측면 필터를 제공한다. 로그인 변형은 이전 상세 해시를 보존하며 모의 계정 상태와 내역 메뉴를 표시한다.

## 실행 목록·참고출처

- [variants-manifest.json](variants-manifest.json): 회사 레지스트리 병합용 의미별 대안·상태·실행 경로·의존성.
- [variants-qa.md](variants-qa.md): 실제 브라우저에서 수행할 상태·상호작용 시나리오.
- [출처 기록](../../../ATTRIBUTION.md): 최초 제작 시 참고한 지침과 권리 표시. 원문 파일·추출 텍스트·대조 장부는 배포에 포함하지 않는다.

**필수·권장·우수는 임의로 합치지 않는다.** 과거 원문 열람이나 변형 목록은 모든 규칙의 UI 준수 통과가 아니다. 업무 조건에 맞는 변형을 선택하며 모든 유형을 하나의 의무 흐름으로 강제하지 않는다. 비텍스트 자료·탐색 이점에 따른 결과 배치 대안을 회사 검색 G05에도 반영했다. 피해야 할 사례는 반례 참고이며 추천 자산으로 만들지 않는다.

## 검증 수준

자동 검사는 고정 데이터 검색·정렬·필터·0건·날짜 오류·로그인 예제 입력·신청 유효성·저장 복원·취소 이력·추천 인덱스와 실행 경로·의존성을 확인한다. 이는 실제 DOM 상호작용·스크린 리더·모바일 레이아웃·모든 규칙 의미 준수의 증거가 아니다.

```sh
node --check designs/assets/ui-kit/internal/company/recipes/services/services.js
node --test tests/test_krds_services.cjs
```

실제 브라우저 검증은 부모 에이전트가 담당한다. 다음 시나리오를 데스크톱1280px/모바일390px에서 수행하고 결과를 전체 검증 기록에 남긴다.

1. 방문: 모든 주요 링크 이동, 개인화 안내의 취소/Escape/로그인 동작과 초점 복귀.
2. 검색: 입력 focus→추천, ↓/↑ 순환·Enter 실행·Escape 닫기, 빈 검색15건의10+5 페이지, 범주·기간·정렬·사용자 날짜 오류, 0건 대안, 모의 오류→재시도, 상세·뒤로가기의 조건 보존, 검색 종료.
3. 로그인: 두 방식, 빈값·잘못된값 오류·비밀번호 삭제/표시·붙여넣기, 성공 상태·이전 과업 복귀, 30초 재현→연장10회 이상, 자연 만료, 자발적 로그아웃 홈/만료 별도 화면의 차이.
4. 신청: 자격 미선택·미해당 차단, 방문/온라인 필드 의존, 이전·다음 보존, 임시 저장→새로고침→이어쓰기, 초기화 취소/확정, 확인·수정·모의 접수, 2건 생성→필터·정렬·선택/전체선택·취소→상세 이력, JSON 다운로드, 이 예제 저장값 삭제 취소/확정.
5. 정책: 전체 목록/페이지·필터·검색·0건·초기화, 관심 상태 전환, 상세 제목·본문 이동·자료/신청 직접 링크, 자료검색0건과 TXT 다운로드.
6. 공통: 키보드 순서/포커스, dialog, URL/title, 넘침·잘림, 로딩/비어있음/오류/성공, 콘솔 및 불필요한 네트워크 요청 부재. localStorage 권한 제한 시 실패 안내는 별도로 검증한다.

확장 화면의 구체적인 브라우저 조작 목록은 [확장 검증 시나리오](variants-qa.md)를 따른다. 미검증은 승인이나 통과로 승격하지 않는다. 실제 기관 데이터의 정확성, 보안 검증, 모든 사례의 픽셀 동등성, 보조기술 테스트, 유형별 전체 조합은 후속 적용·검증 영역이다.
