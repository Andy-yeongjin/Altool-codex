# 확인

출처: 행정안전부, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.677–681. 공공누리 제1유형. [참고출처](../../../ATTRIBUTION.md).

## 재사용 범위

[실행 예제](confirm.html)는 Altool이 독립 제작한 프런트엔드 조합 예제다. 공식 구현이나 접근성 인증이 아니며 실제 수집·제출·외부 API 호출은 하지 않는다. `../../dist/company.css`와 `../recipes.css`, `basic-core.js`, `basic.js`를 함께 사용하고 필요한 패턴의 초기화와 DOM만 선택한다. 고객 디자인 원본이 있으면 해당 시각 계약을 우선한다.

### 제공한 상태·변형

- 가상삭제 확인/유지·삭제후빈상태·다시만들기
- 작성중 종료확인/계속작성·목록이동

## 원문 적용 체크리스트

다음은 적용 프로젝트에서 확인할 목록이다. 항목 존재/자동 테스트를 전체 의미적 준수로 해석하지 않는다. 부적합 예제·실제 기관 브랜드·개인정보는 기본 자산으로 복제하지 않았다.

- [ ] BP-677-01: 취소하기 어렵거나 영향이 큰 행동에만 확인을 요청한다.
- [ ] BP-677-02: 행동의 결과와 부작용을 간결하고 구체적으로 설명한다.
- [ ] BP-677-03: 확정과 취소 행동을 모두 제공한다.
- [ ] BP-677-04: 버튼은 '확인/예' 대신 실제 행동을 설명하는 레이블을 쓴다.

## 실제 브라우저 재검증 시나리오

1. 삭제열기→초안유지/Escape→변경없음/초점복원
2. 삭제확정→빈상태·삭제비활성→다시만들기
3. 나가기→계속작성→유지, 다시나가기→목록 URL
4. 390px/1280px에서 잘림·겹침·포커스·주요 동작·콘솔 오류를 확인한다. 키보드와 실제 스크린리더 확인은 별도이며 정적 마크업 검사로 대체하지 않는다.

## 미적용·잔여 검증

- 실제 삭제·복구·서버 트랜잭션·브라우저 이탈 보호는 구현하지 않았다.
- PDF p682–685는 기본 패턴 본문이 아니라 서비스 패턴 장 전환이다. 확인 본문은 p677–681이다.
- 이 파일 작성 시 실제 브라우저 조작 검증은 부모 작업에 인계했다. 자동 규칙/마크업 검사 결과는 `README.md`의 검증 명령과 별도 작업 보고를 확인한다.
