# 첨부파일

출처: 행정안전부, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.651–655. 공공누리 제1유형. [참고출처](../../../ATTRIBUTION.md).

## 재사용 범위

[실행 예제](attachments.html)는 Altool이 독립 제작한 프런트엔드 조합 예제다. 공식 구현이나 접근성 인증이 아니며 실제 수집·제출·외부 API 호출은 하지 않는다. `../../dist/company.css`와 `../recipes.css`, `basic-core.js`, `basic.js`를 함께 사용하고 필요한 패턴의 초기화와 DOM만 선택한다. 고객 디자인 원본이 있으면 해당 시각 계약을 우선한다.

### 제공한 상태·변형

- UTF-8 TXT 실제 파일·3종링크
- 별도 다운로드/새탭 미리보기·실제 바이트 기반표시

## 원문 적용 체크리스트

다음은 적용 프로젝트에서 확인할 목록이다. 항목 존재/자동 테스트를 전체 의미적 준수로 해석하지 않는다. 부적합 예제·실제 기관 브랜드·개인정보는 기본 자산으로 복제하지 않았다.

- [ ] BP-651-01: 인라인·목록·아이콘 링크를 용도에 맞게 선택한다.
- [ ] BP-651-02: 이름·형식·크기 및 필요한 경우 페이지 수를 제공한다.
- [ ] BP-651-03: 다운로드 액션은 실행 전 알아볼 수 있게 설명한다.
- [ ] BP-651-04: 미리보기는 새 탭임을 알리고 다운로드와 구분한다.
- [ ] BP-651-05: 인라인 링크 글자 크기는 주변 본문과 같게 둔다.
- [ ] BP-651-06: 아이콘 링크에는 정확한 파일명을 포함한 접근 가능한 이름을 제공한다.
- [ ] BP-651-07: 문서 본문은 스크린리더가 읽을 수 있는 텍스트, 이미지에는 대체텍스트를 제공한다.

## 실제 브라우저 재검증 시나리오

1. 인라인/목록/아이콘 다운로드 → 같은 TXT 파일과 바이트 확인
2. 미리보기 →새 탭/읽기 가능한 텍스트, 현재화면 유지
3. 390px/1280px에서 잘림·겹침·포커스·주요 동작·콘솔 오류를 확인한다. 키보드와 실제 스크린리더 확인은 별도이며 정적 마크업 검사로 대체하지 않는다.

## 미적용·잔여 검증

- PDF/HWP/스프레드시트 등 여러 포맷의 문서 접근성 인증은 포함하지 않는다.
- 브라우저·호스팅의 Content-Disposition 정책에 따라 다운로드 동작이 달라질 수 있어 실제 배포 환경에서 확인해야 한다.
- 텍스트 파일은 고정 페이지가 없으므로 페이지 수는 N/A라고 명시한다.
- 이 파일 작성 시 실제 브라우저 조작 검증은 부모 작업에 인계했다. 자동 규칙/마크업 검사 결과는 `README.md`의 검증 명령과 별도 작업 보고를 확인한다.
