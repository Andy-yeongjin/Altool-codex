# 목록 탐색

출처: 행정안전부, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.597–601. 공공누리 제1유형. [참고출처](../../../ATTRIBUTION.md).

## 재사용 범위

[실행 예제](list.html)는 Altool이 독립 제작한 프런트엔드 조합 예제다. 공식 구현이나 접근성 인증이 아니며 실제 수집·제출·외부 API 호출은 하지 않는다. `../../dist/company.css`와 `../recipes.css`, `basic-core.js`, `basic.js`를 함께 사용하고 필요한 패턴의 초기화와 DOM만 선택한다. 고객 디자인 원본이 있으면 해당 시각 계약을 우선한다.

### 제공한 상태·변형

- 24건 가상 목록·중요 첫 항목·10개 페이지
- 검색/초기화/빈결과/이전·다음
- 구조화 목록·표·아코디언 보기

## 원문 적용 체크리스트

다음은 적용 프로젝트에서 확인할 목록이다. 항목 존재/자동 테스트를 전체 의미적 준수로 해석하지 않는다. 부적합 예제·실제 기관 브랜드·개인정보는 기본 자산으로 복제하지 않았다.

- [ ] BP-597-01: 중요한 항목은 상단에 배치한다.
- [ ] BP-597-02: 관련 항목을 의미 단위로 묶고 논리적 순서를 유지한다.
- [ ] BP-597-03: 항목 사이 간격·구분선으로 구분하되 강조 장식은 과도하게 사용하지 않는다.
- [ ] BP-597-04: 긴 목록은 페이지로 나누고 페이지당 기본 10개 이상을 표시한다.
- [ ] BP-597-05: 많은 항목은 검색·필터로 탐색할 수 있게 한다.
- [ ] BP-597-06: 정보 아이콘은 의미를 텍스트로 제공한다. 파일 아이콘 링크의 이름은 실제 파일명을 제공한다.
- [ ] BP-597-07: 표·목록·아코디언의 구조를 의미 있는 HTML로 제공한다.

## 실제 브라우저 재검증 시나리오

1. 초기 10건/3페이지 → 다음10건 → 마지막4건
2. 없는 검색어 →0개+복구안내, 초기화 →24개
3. 3종 보기 전환, 아코디언 열기, 상세 링크 제목 일치
4. 390px/1280px에서 잘림·겹침·포커스·주요 동작·콘솔 오류를 확인한다. 키보드와 실제 스크린리더 확인은 별도이며 정적 마크업 검사로 대체하지 않는다.

## 미적용·잔여 검증

- 상세→목록 검색·보기·페이지·스크롤·초점·열린 아코디언 복원은 구현되어 있다. 실제 대용량 서버 검색과 권한별 데이터 반환만 서비스 어댑터 경계다.
- 첨부파일 이름/아이콘은 별도 attachments 예제와 결합할 수 있다. 모든 목록 항목에 첨부파일을 강제하지 않는다.
- 이 파일 작성 시 실제 브라우저 조작 검증은 부모 작업에 인계했다. 자동 규칙/마크업 검사 결과는 `README.md`의 검증 명령과 별도 작업 보고를 확인한다.
