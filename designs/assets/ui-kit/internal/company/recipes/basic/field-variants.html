KRDS 2024.02 참고 · 회사 공통 재사용 UI

입력·동의의 추가 변형

원문·상태별 기계 판독 목록

생년월일 다중 입력

실제 생년월일을 입력하지 마세요. 입력 형태만 확인하며 서버에 전송하지 않습니다.

연습 생년월일 (필수)

연도 4자리, 월, 일 1~2자리를 입력하세요. 예: 2000년 1월 1일.

체크박스 동의 대안

법적 약관이 아닌 UI 연습입니다. 체크 해제는 동의하지 않음을 뜻하며 선택 동의를 거부해도 진행할 수 있습니다.

동의 항목
[필수] 예제 이용 조건 보기

예제 구조를 살펴보는 조건입니다. 실제 정보를 보내거나 동의 증거를 생성하지 않습니다.

[선택] 연습 소식 안내 보기

선택 동의 항목의 예시입니다. 어떤 소식도 전송하지 않습니다.

폼 레이블·액션·제출 상태

필수 표시와 버튼 배치 대안을 비교합니다. 실제 정보 대신 가상 값을 입력하세요.

필수 항목을 입력하세요.

3~20자, 소문자로 시작하는 소문자·숫자·하이픈. 입력 중에 형식을 확인합니다.

출처: 행정안전부, 디지털 정부서비스 UI/UX 가이드라인(2024.02), 기본 패턴 p553–681. 공공누리 제1유형. 자체 제작 UI이며 공식 인증이나 실제 행정 업무가 아닙니다.
