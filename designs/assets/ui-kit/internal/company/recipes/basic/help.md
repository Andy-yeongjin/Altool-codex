# 도움

출처: 행정안전부, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.573–589. 공공누리 제1유형. [참고출처](../../../ATTRIBUTION.md).

## 재사용 범위

[실행 예제](help.html)는 Altool이 독립 제작한 프런트엔드 조합 예제다. 공식 구현이나 접근성 인증이 아니며 실제 수집·제출·외부 API 호출은 하지 않는다. `../../dist/company.css`와 `../recipes.css`, `basic-core.js`, `basic.js`를 함께 사용하고 필요한 패턴의 초기화와 DOM만 선택한다. 고객 디자인 원본이 있으면 해당 시각 계약을 우선한다.

### 제공한 상태·변형

- 안내 영역·레이블·인라인·플레이스홀더
- 포커스/클릭/Escape 툴팁·맥락 details·도움패널
- 2단계 따라하기·강조 대상·FAQ 새 탭

## 원문 적용 체크리스트

다음은 적용 프로젝트에서 확인할 목록이다. 항목 존재/자동 테스트를 전체 의미적 준수로 해석하지 않는다. 부적합 예제·실제 기관 브랜드·개인정보는 기본 자산으로 복제하지 않았다.

- [ ] BP-573-01: 과업 복잡도와 숙련도에 맞춰 고정형·요청형·별도 도움을 선택한다.
- [ ] BP-573-02: 도움말은 간결하고 관련성 있게, 특정 환경에만 통하는 내용이 아닌 포괄적 설명으로 작성한다.
- [ ] BP-573-03: 요청형 도움의 핵심 내용은 자주 묻는 질문 등 별도 탐색 경로에서도 제공한다.
- [ ] BP-573-04: 같은 기능·화면 이름을 일관되게 사용하고 관련 리소스는 새 탭임을 표시해 현재 작업을 보존한다.
- [ ] BP-573-05: 전체 작업에 중요한 안내 영역은 본문 위 한 곳에 두며 반드시 알아야 할 내용을 접지 않는다.
- [ ] BP-573-06: 플레이스홀더를 레이블·도움말의 대체로 쓰지 않는다.
- [ ] BP-573-07: 작업 완수에 필수인 정보는 필드 옆 인라인 텍스트로 제공한다.
- [ ] BP-573-08: 툴팁은 간단한 추가 설명, 맥락 도움은 요소의 상세 의미에 사용한다.
- [ ] BP-573-09: 많은 도움 콘텐츠는 패널로 제공한다.
- [ ] BP-573-10: 드물고 복잡한 단계 작업에는 코치마크·따라하기를 제공하고 종료·이전·다음 제어를 둔다.

## 실제 브라우저 재검증 시나리오

1. 툴팁 키보드 포커스 → 표시, Escape → 닫기
2. 도움 패널 열기 → 시작/다음/이전/그만보기/마치기 → 강조 해제
3. 제목 미리보기 → 입력 텍스트, FAQ 링크 새 탭
4. 390px/1280px에서 잘림·겹침·포커스·주요 동작·콘솔 오류를 확인한다. 키보드와 실제 스크린리더 확인은 별도이며 정적 마크업 검사로 대체하지 않는다.

## 미적용·잔여 검증

- 추가 작성·검토 주제와 패널·코치마크 3단계 흐름은 `content-variants.html#help-tours`에 제공한다. 실제 업무 문구와 단계 대상만 교체해 사용한다.
- PDF 예제 서비스 화면·브랜드를 복제하지 않았으며 툴팁/코치마크 시각 일치는 주장하지 않는다.
- 이 파일 작성 시 실제 브라우저 조작 검증은 부모 작업에 인계했다. 자동 규칙/마크업 검사 결과는 `README.md`의 검증 명령과 별도 작업 보고를 확인한다.
