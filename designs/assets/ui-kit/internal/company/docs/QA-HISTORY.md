## 남은 실제 화면 확인

현재 환경에 실행 가능한 Chromium이 없어 브라우저 렌더링·실제 computed style·마우스/키보드 동작은 검증하지 못했습니다.
따라서 화면상 스타일 충돌이 없다고 확정하지 않습니다. catalog.html과 개별 예시를 실제 앱 브라우저에서 확인해야 합니다.
특히 Pretendard 로딩, 긴 한글·큰 숫자, 320px 폭, 200% 확대, disabled/hover/focus, 팝업 포커스,
진행률 0~100%, 앱의 다른 CSS와 함께 로딩했을 때의 결과를 확인하세요.

이 ZIP에는 폰트 파일과 실제 업무 API가 포함되어 있지 않습니다.
디자인 선택과 코드 수준 점검은 완료했으며, 브라우저 시각·동작 검증은 완료 범위에 포함되지 않습니다.
