# 01. 날짜 입력 필드(Date input) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.500-512. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 날짜 의미·입력형식 레이블, 원본 문서 형식 일치, 대략적 날짜의 적합성을 확인한다.
- [ ] 키보드 직접입력·달력 선택·형식오류·월/윤년 경계와 가능한 자동완성을 확인한다. 모든 날짜를 근거 없이 불완전 입력으로 허용하지 않는다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 입력 필드에 레이블을 제공하고 어떤 날짜를 입력해야 하는지 명확하게 설명한다. ([p.504](../reference/krds-p0500.md#pdf-p504), [p.505](../reference/krds-p0500.md#pdf-p505))
- [ ] **R002** 도움말 텍스트를 활용하여 날짜 입력 형식을 안내한다. ([p.504](../reference/krds-p0500.md#pdf-p504), [p.506](../reference/krds-p0500.md#pdf-p506))
- [ ] **R003** 문서에 표시된 날짜를 정확하게 요청할 때 입력 필드의 구성을 원본 형식과 일치시킨다. ([p.504](../reference/krds-p0500.md#pdf-p504), [p.507](../reference/krds-p0500.md#pdf-p507))
- [ ] **R004** 사용자가 대략적인 날짜를 입력할 수 있도록 한다. ([p.504](../reference/krds-p0500.md#pdf-p504), [p.508](../reference/krds-p0500.md#pdf-p508))
- [ ] **R005** 사용자가 자주, 반복적으로 입력하는 날짜는 자동 완성될 수 있도록 구현한다. ([p.504](../reference/krds-p0500.md#pdf-p504))
- [ ] **R006** 사용자가 자주, 반복적으로 입력하는 날짜는 자동 완성될 수 있도록 구현한다 사용자에게 개인 정보를 입력받는 입력 필드(생년월일 등)에 프로그램(웹 브라우저)을 통해 사용자가 기존에 입력한 정보를 활용할 수 있는 기술을 적용한다. 이를 통해 정보 입력에 필요한 사용자의 인지적, 신체적 노력을 최소화할 수 있다. ([p.510](../reference/krds-p0500.md#pdf-p510))
- [ ] **R007** 키보드를 이용하여 조회 날짜를 선택하거나 입력할 수 있도록 제공한다. ([p.511](../reference/krds-p0500.md#pdf-p511))
- [ ] **R008** 입력 필드에 레이블을 명확하게 지정한다. ([p.511](../reference/krds-p0500.md#pdf-p511))
- [ ] **R009** 날짜 입력 형식이 지정되어 있는 경우 사용자에게 입력 방식을 명확하게 안내한다. ([p.511](../reference/krds-p0500.md#pdf-p511))
