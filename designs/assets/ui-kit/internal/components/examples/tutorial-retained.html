자료 카드 만들기 · 로컬 예제

제목·분류로 화면 안의 미리보기만 만듭니다. 서버 전송이나 저장은 하지 않습니다.

1~40자 제목을 입력하고 적용해 주세요.

따라하기를 시작하지 않았습니다.

자료 카드란?

제목과 분류를 요약한 미리보기입니다. 실제 자료는 업로드하거나 저장하지 않습니다.

  1. 제목 적용
  2. 분류 선택
  3. 미리보기 생성

시작 전

접기와 탭 전환은 현재 진행을 유지합니다. 그만하기는 안내를 중단합니다. 새로고침하면 초기 상태로 돌아갑니다.
