선택형 로컬 이미지 용량 줄이기

Altool 작성 재사용 UI · KRDS 2024.02 참고. 샘플 데이터이며 전송·로그인·실제 업무 처리는 연결하지 않았습니다.

이미지 용량 줄이기

이미지 제출과 용량 제한이 모두 필요한 경우에만 선택합니다. JPG·PNG·WebP 파일을 최대 1600픽셀, JPEG 품질 80%로 로컬 변환합니다. 투명 배경은 흰색이 되며 원본은 변경하거나 전송하지 않습니다. 이미지 품질과 결과 용량을 확인한 후 선택하세요.

결과가 더 크면 원본 유지를 안내합니다. 호스트는 altool:change의 최적화된 File을 사용하기 전에 업무별 화질·형식·용량 조건을 검증합니다.
