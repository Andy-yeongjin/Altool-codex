# 02. 운영기관 식별자(Identifier) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.121-127. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

> **공식정부서비스 전용. 일반 제품에서는 사용하지 않는다.**

## 적용 전 판단과 실제 검증

- [ ] 비정부 사이트에서는 기관 식별자를 사용하지 않는다.
- [ ] 기관 계층에 따른 로고 순서·대체 텍스트·고정 안내를 확인하고 식별자가 푸터 안에 있는지 검사한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 식별자가 지나치게 주의를 끌지 않도록 표현한다. ([p.124](../reference/krds-p0121.md#pdf-p124), [p.125](../reference/krds-p0121.md#pdf-p125))
- [ ] **R002** 로고 영역에는 서비스의 로고나 서비스 운영 주체의 로고가 아니라 서비스 운영과 관련된 상위 기관의 로고를 제공한다. ([p.124](../reference/krds-p0121.md#pdf-p124), [p.125](../reference/krds-p0121.md#pdf-p125))
- [ ] **R003** 관련 기관이 2개 이상 존재하는 경우 기관의 계층 수준에 따라 로고를 순서대로 배치한다. ([p.124](../reference/krds-p0121.md#pdf-p124), [p.125](../reference/krds-p0121.md#pdf-p125))
- [ ] **R004** 안내 텍스트와 요소의 배치를 변경하지 않는다. ([p.124](../reference/krds-p0121.md#pdf-p124), [p.126](../reference/krds-p0121.md#pdf-p126))
- [ ] **R005** 공식 디지털 정부서비스가 아닌 사이트에서는 식별자를 사용하지 않아야 한다. ([p.124](../reference/krds-p0121.md#pdf-p124), [p.126](../reference/krds-p0121.md#pdf-p126))
- [ ] **R006** 식별자 영역은 구조적으로 푸터 내부에 포함되도록 제공한다. ([p.127](../reference/krds-p0121.md#pdf-p127))
- [ ] **R007** 로고 이미지에 대체 텍스트를 제공한다. ([p.127](../reference/krds-p0121.md#pdf-p127))
