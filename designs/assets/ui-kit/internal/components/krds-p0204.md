# 05. 콘텐츠 내 탐색(In-page navigation) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.204-212. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 본문 우측 배치와 문서상 제목-본문 사이 순서를 구분한다. 모바일에서는 본문 앞에 배치한다.
- [ ] 최대 3단계 링크와 섹션 제목의 일치, 실제 목적지 ID·키보드 초점 이동을 확인한다. upstream 조각만으로 대상 섹션은 생기지 않는다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 적절한 너비로 표현한다. ([p.207](../reference/krds-p0204.md#pdf-p207), [p.208](../reference/krds-p0204.md#pdf-p208))
- [ ] **R002** 콘텐츠 내 탐색은 본문 우측에 표시한다. ([p.207](../reference/krds-p0204.md#pdf-p207), [p.208](../reference/krds-p0204.md#pdf-p208))
- [ ] **R003** 개요 목록 텍스트는 연결된 섹션 제목과 일치하는 내용으로 제공한다. ([p.207](../reference/krds-p0204.md#pdf-p207), [p.208](../reference/krds-p0204.md#pdf-p208))
- [ ] **R004** 목록 수준은 최대 3단계까지 사용한다. ([p.207](../reference/krds-p0204.md#pdf-p207), [p.208](../reference/krds-p0204.md#pdf-p208))
- [ ] **R005** 모바일에서 콘텐츠 내 탐색은 제목과 본문 사이에 배치한다. ([p.209](../reference/krds-p0204.md#pdf-p209))
- [ ] **R006** 키보드로 접근과 조작이 가능하도록 한다. ([p.210](../reference/krds-p0204.md#pdf-p210))
- [ ] **R007** 콘텐츠 내 탐색은 제목과 본문 사이에 배치한다. ([p.210](../reference/krds-p0204.md#pdf-p210))
- [ ] **R008** 키보드로 콘텐츠 내 탐색 링크를 실행하였을 때 화면과 함께 키보드 초점이 해당 섹션으로 이동되도록 한다. ([p.210](../reference/krds-p0204.md#pdf-p210))
- [ ] **R009** 링크 목록에 <h1>을 사용하지 않는다. ([p.211](../reference/krds-p0204.md#pdf-p211))
