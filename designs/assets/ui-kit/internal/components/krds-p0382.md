# 01. 라디오 버튼(Radio button) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.382-396. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 명확한 그룹/옵션 레이블, 기본 선택의 적합성, 가나다순 또는 합리적 대안 순서를 확인한다.
- [ ] 키보드 방향키·선택, 그룹 내 단일 선택, 비색상 상태, disabled·초점·충분한 간격을 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 기본적으로 라디오 버튼의 옵션은 가나다순으로 정렬한다. ([p.385](../reference/krds-p0382.md#pdf-p385), [p.386](../reference/krds-p0382.md#pdf-p386))
- [ ] **R002** 라디오 버튼은 수직으로, 라디오 버튼의 레이블은 양식의 오른쪽에 배치한다. ([p.385](../reference/krds-p0382.md#pdf-p385), [p.387](../reference/krds-p0382.md#pdf-p387))
- [ ] **R003** 라디오 버튼을 수평으로 배치하는 경우 버튼 간 간격을 충분히 제공한다. ([p.385](../reference/krds-p0382.md#pdf-p385), [p.388](../reference/krds-p0382.md#pdf-p388))
- [ ] **R004** 라디오 버튼의 레이블은 분명하고 정확하게 제공한다. ([p.385](../reference/krds-p0382.md#pdf-p385), [p.389](../reference/krds-p0382.md#pdf-p389))
- [ ] **R005** 사용자가 정확한 값을 입력하는 것이 중요한 경우 라디오 버튼의 특정 옵션을 기본 선택값으로 제공하지 않아야 한다. ([p.385](../reference/krds-p0382.md#pdf-p385), [p.390](../reference/krds-p0382.md#pdf-p390))
- [ ] **R006** '해당 없음', '잘 모름' 옵션 제공을 고려한다. ([p.385](../reference/krds-p0382.md#pdf-p385), [p.391](../reference/krds-p0382.md#pdf-p391))
- [ ] **R007** 버튼 양식과 인접 배경 간 명도 대비를 3:1 이상으로 표현한다. ([p.392](../reference/krds-p0382.md#pdf-p392))
- [ ] **R008** 버튼 양식의 선택 상태를 색상으로만 구분하지 않는다. ([p.393](../reference/krds-p0382.md#pdf-p393))
- [ ] **R009** 라디오 버튼을 키보드로 탐색하고 실행할 수 있도록 한다. ([p.394](../reference/krds-p0382.md#pdf-p394))
- [ ] **R010** 라디오 버튼에 키보드 초점이 명확하게 표시되도록 한다. ([p.394](../reference/krds-p0382.md#pdf-p394))
- [ ] **R011** 라디오 버튼에 접근 가능한 이름을 제공한다. ([p.395](../reference/krds-p0382.md#pdf-p395))
- [ ] **R012** 스크린 리더에서 그룹 레이블과 라디오 버튼 그룹의 관계를 확인할 수 있도록 한다. ([p.395](../reference/krds-p0382.md#pdf-p395))
