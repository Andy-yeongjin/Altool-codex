# 02. 텍스트 영역(Textarea) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.513-521. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 고정 레이블·적절한 높이·글자 수 안내를 제공하고 placeholder로 레이블을 대신하지 않는다.
- [ ] 키보드·복사/붙여넣기·최대 길이·초점·오류·작은 화면에서의 입력 내용을 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 입력 영역은 텍스트의 길이를 고려하여 적절한 크기로 제공한다. ([p.515](../reference/krds-p0513.md#pdf-p515), [p.516](../reference/krds-p0513.md#pdf-p516))
- [ ] **R002** 모든 텍스트 영역에는 레이블을 제공한다. ([p.515](../reference/krds-p0513.md#pdf-p515), [p.516](../reference/krds-p0513.md#pdf-p516))
- [ ] **R003** 플레이스홀더가 레이블이나 도움말의 대체 수단으로 사용되어서는 안 된다. ([p.515](../reference/krds-p0513.md#pdf-p515), [p.517](../reference/krds-p0513.md#pdf-p517))
- [ ] **R004** 복사, 붙여넣기를 제한하지 않는다. ([p.515](../reference/krds-p0513.md#pdf-p515), [p.518](../reference/krds-p0513.md#pdf-p518))
- [ ] **R005** 입력 가능한 글자 수에 제한이 있는 경우 사용자에게 글자 수 정보를 제공한다. ([p.515](../reference/krds-p0513.md#pdf-p515), [p.519](../reference/krds-p0513.md#pdf-p519))
- [ ] **R006** 입력 영역과 인접 배경 간 명도 대비를 3:1 이상으로 제공한다. ([p.520](../reference/krds-p0513.md#pdf-p520))
- [ ] **R007** 텍스트 영역에 접근 가능한 이름을 제공한다. ([p.520](../reference/krds-p0513.md#pdf-p520))
