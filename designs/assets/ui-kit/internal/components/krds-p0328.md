# 10. 탭(Tab) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.328-341. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 탭/패널 연결, 선택값, 방향키·Tab 초점, 패널 전환을 확인한다. 자료가 없는 탭은 이유를 설명하거나 제거한다.
- [ ] 순서가 중요한 과업·서로 비교할 내용에 탭을 남용하지 않고 많거나 긴 탭의 모바일 탐색 수단을 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 사용자가 탭과 탭 패널 간 관계를 명확하게 인지할 수 있도록 표현한다. ([p.331](../reference/krds-p0328.md#pdf-p331), [p.332](../reference/krds-p0328.md#pdf-p332))
- [ ] **R002** 탭 레이블은 표시할 콘텐츠 섹션의 정보를 예측할 수 있는 명확한 내용으로 제공한다. ([p.331](../reference/krds-p0328.md#pdf-p331), [p.333](../reference/krds-p0328.md#pdf-p333))
- [ ] **R003** 탭에 사용 불가 상태를 사용하지 않는다. ([p.331](../reference/krds-p0328.md#pdf-p331), [p.334](../reference/krds-p0328.md#pdf-p334))
- [ ] **R004** 여러 개의 탭을 중첩하는 경우, 서로 다른 수준의 탭이 명확하게 구분되도록 표현한다. ([p.331](../reference/krds-p0328.md#pdf-p331), [p.335](../reference/krds-p0328.md#pdf-p335))
- [ ] **R005** 수직 탭은 탭을 수평으로 배치하기 어려운 경우에 사용한다. ([p.331](../reference/krds-p0328.md#pdf-p331), [p.336](../reference/krds-p0328.md#pdf-p336))
- [ ] **R006** 탭의 항목 수가 많아 일렬로 배치하기 어려운 경우 별도의 탐색 컨트롤을 제공한다. ([p.331](../reference/krds-p0328.md#pdf-p331), [p.337](../reference/krds-p0328.md#pdf-p337))
- [ ] **R007** 탭의 선택 상태를 색상으로만 구분하지 않는다. ([p.338](../reference/krds-p0328.md#pdf-p338))
- [ ] **R008** 탭을 키보드로 탐색하고 실행할 수 있도록 한다. ([p.339](../reference/krds-p0328.md#pdf-p339))
- [ ] **R009** 탭의 키보드 초점이 명확하게 표시되도록 한다. ([p.339](../reference/krds-p0328.md#pdf-p339))
- [ ] **R010** 탭의 선택 상태를 스크린 리더로 확인할 수 있도록 한다. ([p.339](../reference/krds-p0328.md#pdf-p339))
- [ ] **R011** 탭과 패널의 역할 및 관계를 스크린 리더로 확인할 수 있도록 한다. ([p.340](../reference/krds-p0328.md#pdf-p340))
