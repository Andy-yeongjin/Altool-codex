# 01. 링크(Link) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.354-367. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 실제 목적지로 이동하며 링크명이 목적지를 설명하는지 확인한다. 색상만으로 링크를 구별하지 않는다.
- [ ] 외부/새 창 안내·이메일/전화 링크·접근 가능한 고유 이름·키보드 조작·조작 크기를 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 링크가 인라인으로 사용될 때 링크 텍스트를 주변 텍스트와 동일한 크기로 제공한다. ([p.357](../reference/krds-p0354.md#pdf-p357), [p.358](../reference/krds-p0354.md#pdf-p358))
- [ ] **R002** 링크와 관련된 사용자 과업, 플로 (Flow) 의 중요도에 따라 위계를 명확하게 구분한다. ([p.357](../reference/krds-p0354.md#pdf-p357), [p.359](../reference/krds-p0354.md#pdf-p359))
- [ ] **R003** 링크를 색상만으로 구분하지 않는다. ([p.357](../reference/krds-p0354.md#pdf-p357), [p.360](../reference/krds-p0354.md#pdf-p360))
- [ ] **R004** 링크 레이블은 연결된 목적지 정보를 예측할 수 있는 내용으로 제공한다. ([p.357](../reference/krds-p0354.md#pdf-p357), [p.361](../reference/krds-p0354.md#pdf-p361))
- [ ] **R005** 이메일 주소, 전화번호 정보를 링크로 제공한다. ([p.357](../reference/krds-p0354.md#pdf-p357), [p.362](../reference/krds-p0354.md#pdf-p362))
- [ ] **R006** 외부 서비스로 이동하는 링크를 분명하게 구분하고 일관된 방식으로 표현한다. ([p.357](../reference/krds-p0354.md#pdf-p357), [p.363](../reference/krds-p0354.md#pdf-p363))
- [ ] **R007** 링크는 레이블의 설명과 가장 관련성이 높은 목적지로 바로 이동할 수 있도록 구성한다. ([p.357](../reference/krds-p0354.md#pdf-p357), [p.364](../reference/krds-p0354.md#pdf-p364))
- [ ] **R008** 비활성화, 사용불가 상태인 경우를 제외하고 모든 링크는 키보드로 접근하고 조작할 수 있도록 한다. ([p.365](../reference/krds-p0354.md#pdf-p365))
- [ ] **R009** 링크 텍스트는 링크 목적지 정보를 적절하게 설명할 수 있는 내용으로 제공한다. ([p.365](../reference/krds-p0354.md#pdf-p365))
- [ ] **R010** 링크 레이블은 고유한 내용으로 제공한다. ([p.365](../reference/krds-p0354.md#pdf-p365))
- [ ] **R011** 링크를 적절한 크기로 제공한다. ([p.366](../reference/krds-p0354.md#pdf-p366))
- [ ] **R012** 링크로 작동하는 모든 요소는 스크린 리더에서 링크로 인지될 수 있도록 한다. ([p.366](../reference/krds-p0354.md#pdf-p366))
