# 03. 브레드크럼(Breadcrumb) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.176-188. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 메인부터 현재 화면의 상위 화면까지 경로를 제공하는 2024 규칙을 후대 키트와 대조한다.
- [ ] nav와 순서목록, 숨긴 장식 구분자, 1행/모바일 생략, 실제 상위 링크 이동을 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 브레드크럼 목록의 가장 첫 번째 항목으로 메인 화면 링크를 제공한다. ([p.178](../reference/krds-p0176.md#pdf-p178), [p.179](../reference/krds-p0176.md#pdf-p179))
- [ ] **R002** 브레드크럼 목록의 가장 마지막 항목으로 현재 화면의 상위 화면 링크를 제공한다. ([p.178](../reference/krds-p0176.md#pdf-p178), [p.180](../reference/krds-p0176.md#pdf-p180))
- [ ] **R003** 상위 화면으로 연결되는 링크가 없는 경우에도 항상 현재 화면의 전체 정보 계층 구조를 표시한다. ([p.178](../reference/krds-p0176.md#pdf-p178), [p.181](../reference/krds-p0176.md#pdf-p181))
- [ ] **R004** 브레드크럼 텍스트 경로가 링크임을 인지할 수 있는 시각적 단서를 제공한다. ([p.178](../reference/krds-p0176.md#pdf-p178), [p.181](../reference/krds-p0176.md#pdf-p181))
- [ ] **R005** 브레드크럼은 단일 행으로 제공한다. ([p.178](../reference/krds-p0176.md#pdf-p178), [p.182](../reference/krds-p0176.md#pdf-p182))
- [ ] **R006** 브레드크럼은 항상 본문 제목의 왼쪽 상단에 표시한다. ([p.178](../reference/krds-p0176.md#pdf-p178), [p.183](../reference/krds-p0176.md#pdf-p183))
- [ ] **R007** 브레드크럼 경로 링크 간 간격을 충분히 제공한다. ([p.178](../reference/krds-p0176.md#pdf-p178), [p.183](../reference/krds-p0176.md#pdf-p183))
- [ ] **R008** 브레드크럼이 메인 메뉴나 사이드 메뉴를 대체해서는 안 된다. ([p.178](../reference/krds-p0176.md#pdf-p178), [p.184](../reference/krds-p0176.md#pdf-p184))
- [ ] **R009** 화면 너비가 충분하지 않은 경우 첫 번째 경로와 마지막 경로만 표시한다. ([p.185](../reference/krds-p0176.md#pdf-p185))
- [ ] **R010** 경로 목록을 <nav> 구획으로 감싸고 적절한 구획 제목을 제공한다. ([p.186](../reference/krds-p0176.md#pdf-p186))
- [ ] **R011** 순서 있는 목록을 사용한다. ([p.186](../reference/krds-p0176.md#pdf-p186))
- [ ] **R012** 구분자는 배경과 3:1 이상의 명도 대비를 갖도록 표현한다. ([p.186](../reference/krds-p0176.md#pdf-p186))
- [ ] **R013** 스크린 리더에서 구분자 정보가 탐지되지 않도록 한다. ([p.187](../reference/krds-p0176.md#pdf-p187))
