# 03. 달력(Calendar) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.251-261. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 요일 헤딩, 오늘·선택·일정 상태의 범례와 비색상 단서, 복잡한 이벤트 상세를 확인한다.
- [ ] 이전/다음 달, 키보드 날짜 탐색, 윤년·월 경계, 범위 선택이 있는 경우 시작·끝을 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 날짜의 여러 가지 상태, 정보의 범례는 일관성 있게 표현한다. ([p.254](../reference/krds-p0251.md#pdf-p254), [p.255](../reference/krds-p0251.md#pdf-p255))
- [ ] **R002** 날짜의 여러 가지 상태 정보가 서로 명확하게 구분되도록 표현한다. ([p.254](../reference/krds-p0251.md#pdf-p254), [p.256](../reference/krds-p0251.md#pdf-p256))
- [ ] **R003** 이벤트 정보가 복잡한 경우 정보를 손실 없이 확인할 수 있는 수단을 제공한다. ([p.254](../reference/krds-p0251.md#pdf-p254), [p.257](../reference/krds-p0251.md#pdf-p257))
- [ ] **R004** 달력 그리드에 헤딩(요일) 정보를 반드시 제공한다. ([p.254](../reference/krds-p0251.md#pdf-p254), [p.258](../reference/krds-p0251.md#pdf-p258))
- [ ] **R005** 날짜 및 관련 정보의 의미를 색상으로만 구분하지 않는다. ([p.259](../reference/krds-p0251.md#pdf-p259))
- [ ] **R006** 날짜 및 관련 정보의 의미를 스크린 리더에서 확인할 수 있도록 한다. ([p.259](../reference/krds-p0251.md#pdf-p259))
- [ ] **R007** 달력에서 제공되는 모든 기능을 키보드로 실행할 수 있도록 한다. ([p.259](../reference/krds-p0251.md#pdf-p259))
- [ ] **R008** 달력에서 제공되는 모든 기능에 키보드 초점이 명확하게 표시되도록 한다. ([p.260](../reference/krds-p0251.md#pdf-p260))
