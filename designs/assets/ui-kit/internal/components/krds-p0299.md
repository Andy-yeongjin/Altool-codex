# 08. 이미지(Image) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.299-306. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 정보·장식·기능 이미지 목적을 구분한다. alt에는 중복 역할·저작자·없는 사실을 넣지 않는다.
- [ ] 설명을 HTML로 제공하고 비대화형 이미지에 클릭·Tab을 부여하지 않는다. 기능이 있으면 별도 링크/버튼에 이름을 준다.
- [ ] 모바일 리사이즈·자산 실패·대체 설명, 실제 이미지의 해상도·크롭을 확인한다. 정보도식 예제는 사진 품질 검증을 대신하지 않는다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 이미지 콘텐츠를 사용하는 목적에 대해 가장 먼저 정의한다. ([p.301](../reference/krds-p0299.md#pdf-p301), [p.302](../reference/krds-p0299.md#pdf-p302))
- [ ] **R002** 이미지에 텍스트를 합성할 때 스타일에 유의한다. ([p.301](../reference/krds-p0299.md#pdf-p301), [p.302](../reference/krds-p0299.md#pdf-p302))
- [ ] **R003** 이미지에 대체 텍스트 또는 설명을 제공한다. ([p.301](../reference/krds-p0299.md#pdf-p301), [p.303](../reference/krds-p0299.md#pdf-p303))
- [ ] **R004** 사용자의 화면 크기, 접속 환경을 고려하여 이미지 계획을 수립한다. ([p.304](../reference/krds-p0299.md#pdf-p304))
- [ ] **R005** 장식용 이미지를 제외한 모든 이미지에 대체 텍스트를 제공한다. ([p.305](../reference/krds-p0299.md#pdf-p305))
- [ ] **R006** 가능한 한 이미지 텍스트를 사용하지 않는다. ([p.305](../reference/krds-p0299.md#pdf-p305))
