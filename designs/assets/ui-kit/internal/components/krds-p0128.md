# 03. 푸터(Footer) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.128-134. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 개인정보 처리방침, 필요한 약관, 연락처의 실제 목적지와 최신성을 확인한다.
- [ ] 공통 푸터 정보 순서와 기본 내비게이션 명칭 일치, 모바일 정보 유지, contentinfo 탐색을 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 모든 화면에 푸터를 일관된 위치에 제공해야 한다. ([p.129](../reference/krds-p0128.md#pdf-p129), [p.130](../reference/krds-p0128.md#pdf-p130))
- [ ] **R002** 모든 디지털 정부서비스에서 푸터 섹션의 정보는 일관된 순서로 제공한다. ([p.129](../reference/krds-p0128.md#pdf-p129), [p.131](../reference/krds-p0128.md#pdf-p131))
- [ ] **R003** 개인 정보 처리 방침을 반드시 표시한다. ([p.129](../reference/krds-p0128.md#pdf-p129), [p.131](../reference/krds-p0128.md#pdf-p131))
- [ ] **R004** 전자상거래가 포함된 경우 이용약관을 반드시 표시한다. ([p.129](../reference/krds-p0128.md#pdf-p129), [p.131](../reference/krds-p0128.md#pdf-p131))
- [ ] **R005** 사용자들이 빈번하게 찾는 링크를 배치한다. ([p.129](../reference/krds-p0128.md#pdf-p129), [p.132](../reference/krds-p0128.md#pdf-p132))
- [ ] **R006** 푸터에 제공하는 서비스 내비게이션은 기본 내비게이션과 동일한 구조 및 레이블을 따라야 한다. ([p.129](../reference/krds-p0128.md#pdf-p129), [p.132](../reference/krds-p0128.md#pdf-p132))
- [ ] **R007** 연락처 정보와 각종 링크는 항상 최신 상태로 유지한다. ([p.129](../reference/krds-p0128.md#pdf-p129), [p.132](../reference/krds-p0128.md#pdf-p132))
- [ ] **R008** 작은 화면 너비에서도 푸터의 정보 요소는 상대적으로 동일한 순서로 제공되도록 표현한다. ([p.133](../reference/krds-p0128.md#pdf-p133))
- [ ] **R009** 푸터 영역이 스크린 리더에 인지될 수 있는 방식으로 제공한다. ([p.134](../reference/krds-p0128.md#pdf-p134))
- [ ] **R010** 로고 이미지에 대체 텍스트를 제공한다. ([p.134](../reference/krds-p0128.md#pdf-p134))
