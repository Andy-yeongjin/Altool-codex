# 02. 긴급 공지(Critical alerts) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.243-250. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 시급한 공지는 한 개만, 필요 기간만 표시하고 숨기기 버튼을 제공하지 않는다.
- [ ] 공지의 중요성·문구·링크 목적지와 배너 역할, 장식 아이콘 숨김, 작은 화면의 문구 표시를 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 시급하고 사용자에게 중요한 정보를 전달하는 데 긴급 공지를 사용한다. ([p.245](../reference/krds-p0243.md#pdf-p245), [p.246](../reference/krds-p0243.md#pdf-p246))
- [ ] **R002** 일시적으로 게시하고 정보가 필요한 기간 동안만 유지한다. ([p.245](../reference/krds-p0243.md#pdf-p245), [p.246](../reference/krds-p0243.md#pdf-p246))
- [ ] **R003** 눈에 잘 띄게 표현하고 배치한다. ([p.245](../reference/krds-p0243.md#pdf-p245), [p.246](../reference/krds-p0243.md#pdf-p246))
- [ ] **R004** 긴급 공지 배너 숨기기 버튼을 제공하지 않는다. ([p.245](../reference/krds-p0243.md#pdf-p245), [p.247](../reference/krds-p0243.md#pdf-p247))
- [ ] **R005** 공지 내용은 이해하기 쉽고 간결하게 작성한다. ([p.245](../reference/krds-p0243.md#pdf-p245), [p.247](../reference/krds-p0243.md#pdf-p247))
- [ ] **R006** 여러 개의 긴급 공지를 사용하지 않는다. ([p.245](../reference/krds-p0243.md#pdf-p245), [p.247](../reference/krds-p0243.md#pdf-p247))
- [ ] **R007** 관련 화면으로 이동하기 위한 링크를 여러 개 사용하지 않는다. ([p.245](../reference/krds-p0243.md#pdf-p245), [p.248](../reference/krds-p0243.md#pdf-p248))
- [ ] **R008** 화면 너비가 충분하지 않은 경우 텍스트는 2줄까지 표현할 수 있다. ([p.249](../reference/krds-p0243.md#pdf-p249))
- [ ] **R009** 긴급 공지 섹션에 배너 역할을 제공한다. ([p.250](../reference/krds-p0243.md#pdf-p250))
- [ ] **R010** 아이콘에 대체 텍스트를 제공하지 않는다. ([p.250](../reference/krds-p0243.md#pdf-p250))
- [ ] **R011** 목적지를 예측할 수 있는 링크 이름 또는 부가 설명을 제공한다. ([p.250](../reference/krds-p0243.md#pdf-p250))
