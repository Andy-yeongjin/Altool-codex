# 02. 스피너(Spinner) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.437-445. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 실제 처리 영역 근처에 처리 상태 설명과 스피너를 제공하고 장식으로 쓰지 않는다.
- [ ] 로딩 시작·성공·실패 전환을 확인한다. 불확정 루프와 중복 스피너 억제, 명도 대비를 검토한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 스피너를 장식용으로 사용하지 않는다. ([p.440](../reference/krds-p0437.md#pdf-p440), [p.441](../reference/krds-p0437.md#pdf-p441))
- [ ] **R002** 상황에 맞는 적절한 크기의 스피너를 사용한다. ([p.440](../reference/krds-p0437.md#pdf-p440), [p.441](../reference/krds-p0437.md#pdf-p441))
- [ ] **R003** 스피너는 처리가 진행 중인 영역 근처에 배치한다. ([p.440](../reference/krds-p0437.md#pdf-p440), [p.441](../reference/krds-p0437.md#pdf-p441))
- [ ] **R004** 불확정 스피너의 애니메이션의 루프를 중지하지 않는다. ([p.440](../reference/krds-p0437.md#pdf-p440), [p.442](../reference/krds-p0437.md#pdf-p442))
- [ ] **R005** 컴포넌트의 일부로 작게 표시되지 않는 한, 두 개 이상의 스피너를 동시에 표시하지 않는다. ([p.440](../reference/krds-p0437.md#pdf-p440), [p.442](../reference/krds-p0437.md#pdf-p442))
- [ ] **R006** 인접 배경과 경로 간 명도 대비, 경로와 식별자 간 명도 대비를 3:1 이상으로 표현한다. ([p.443](../reference/krds-p0437.md#pdf-p443))
- [ ] **R007** 스피너 상태에 대한 설명을 스크린 리더에서 확인할 수 있도록 한다. ([p.443](../reference/krds-p0437.md#pdf-p443))
