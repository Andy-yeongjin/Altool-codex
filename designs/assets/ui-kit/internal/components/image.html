KRDS 2024.02 · 이미지 p.299-306

이미지는 목적에 맞게

정보를 전하는 그림, 장식, 기능 아이콘을 구분하는 재사용 예제입니다.

Altool이 직접 작성한 참고 예제입니다. 실제 정부서비스나 신청 화면이 아닙니다. 사진·기관 로고는 복제하지 않았으며, 이 도식은 제품 사진을 대체하는 자산이 아닙니다.

1. 정보가 있는 이미지

그림의 상세 설명

  1. 신청: 필요한 내용을 작성합니다.
  2. 확인: 작성한 내용이 맞는지 검토합니다.
  3. 결과 안내: 처리가 끝나면 결과를 확인합니다.

중요한 설명은 그림에 합성하지 않고 이처럼 HTML 텍스트로 제공합니다.

2. 의미를 추가하지 않는 장식

위 구분 장식은 빈 대체 텍스트를 사용합니다. 없어도 내용은 동일하게 이해할 수 있습니다.

3. 기능은 링크가 담당

그림의 상세 설명으로 이동

기능 이름은 링크 텍스트로 제공하고 중복 아이콘은 읽지 않습니다. 클릭과 키보드 실행은 이미지가 아닌 링크가 담당합니다.

4. 그림을 표시할 수 없는 상태

안내 그림을 표시할 수 없습니다

신청 내용을 작성하고 확인한 뒤 결과를 안내받는 순서입니다. 위의 상세 설명에서 각 단계를 확인할 수 있습니다.

대체 안내의 정적 상태 예시입니다. 이 페이지는 네트워크 오류를 발생시키거나 복구·재시도 기능을 실행하지 않습니다.
