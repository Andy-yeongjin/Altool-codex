# 07 . 아코디언(Accordion) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.288-298. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 중요 정보를 숨겨도 되는지 먼저 판단하고 탭/아코디언 중첩을 피한다.
- [ ] 헤더 전체 클릭·키보드 실행·펼침 상태·제목 계층·아이콘 방향과 패널 내부 이중 스크롤 부재를 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 아코디언의 확장 상태를 나타내는 아이콘은 항상 일관된 위치에 제공한다. ([p.291](../reference/krds-p0288.md#pdf-p291), [p.292](../reference/krds-p0288.md#pdf-p292))
- [ ] **R002** 아코디언의 확장 상태를 나타내는 아이콘은 패널이 펼쳐지거나 접히는 방향을 정확하게 반영하도록 제공한다. ([p.291](../reference/krds-p0288.md#pdf-p291), [p.293](../reference/krds-p0288.md#pdf-p293))
- [ ] **R003** 헤더 전체를 클릭 가능하도록 만든다. ([p.291](../reference/krds-p0288.md#pdf-p291), [p.294](../reference/krds-p0288.md#pdf-p294))
- [ ] **R004** 헤더와 패널은 서로 관련 있는 것으로 인지될 수 있게 표현한다. ([p.291](../reference/krds-p0288.md#pdf-p291), [p.295](../reference/krds-p0288.md#pdf-p295))
- [ ] **R005** 패널 영역에 스크롤이 발생하지 않도록 한다. ([p.291](../reference/krds-p0288.md#pdf-p291), [p.296](../reference/krds-p0288.md#pdf-p296))
- [ ] **R006** 아코디언에 접근 가능한 제목을 제공한다. ([p.297](../reference/krds-p0288.md#pdf-p297))
- [ ] **R007** 아코디언의 활성화 상태 정보를 스크린 리더에서 확인할 수 있도록 한다. ([p.297](../reference/krds-p0288.md#pdf-p297))
- [ ] **R008** 헤더를 버튼 역할로 제공한다. ([p.297](../reference/krds-p0288.md#pdf-p297))
