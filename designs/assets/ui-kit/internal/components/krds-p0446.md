# 01. 도움 패널(Help panel) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.446-458. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 큰 화면 기본 열림·기본 콘텐츠, 요소 가까운 도움 버튼, 제목 일치를 확인한다.
- [ ] 도움 버튼 실행으로만 내용 변경, 모바일 열기/닫기, 본문 다음 패널 순서, 새 창 안내를 확인한다. 필수 정보는 본문에도 제공한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 화면이 로딩되었을 때 도움 패널은 열린 상태로 제공한다. ([p.449](../reference/krds-p0446.md#pdf-p449), [p.450](../reference/krds-p0446.md#pdf-p450))
- [ ] **R002** 도움 패널의 첫 화면은 기본 상태로 제공한다. ([p.449](../reference/krds-p0446.md#pdf-p449), [p.451](../reference/krds-p0446.md#pdf-p451))
- [ ] **R003** 아이콘 버튼은 도움 정보를 제공하고자 하는 요소 주변에 배치한다. ([p.449](../reference/krds-p0446.md#pdf-p449), [p.452](../reference/krds-p0446.md#pdf-p452))
- [ ] **R004** 도움 패널의 섹션 제목은 아이콘 버튼과 관련된 본문 섹션 제목/레이블 텍스트와 일치해야 한다. ([p.449](../reference/krds-p0446.md#pdf-p449), [p.452](../reference/krds-p0446.md#pdf-p452))
- [ ] **R005** 콘텐츠를 간결하게 유지한다. ([p.449](../reference/krds-p0446.md#pdf-p449), [p.452](../reference/krds-p0446.md#pdf-p452))
- [ ] **R006** 사용자가 작업을 수행하기 위해 반드시 알아야 하는 필수 정보가 패널에서만 제공되지 않도록 한다. ([p.449](../reference/krds-p0446.md#pdf-p449), [p.453](../reference/krds-p0446.md#pdf-p453))
- [ ] **R007** 패널에서 제공하는 웹 페이지 링크는 새 창으로 실행한다. ([p.449](../reference/krds-p0446.md#pdf-p449), [p.453](../reference/krds-p0446.md#pdf-p453))
- [ ] **R008** 본문은 사용자가 특정 아이콘 버튼을 실행하는 경우에만 변경되도록 한다. ([p.449](../reference/krds-p0446.md#pdf-p449), [p.453](../reference/krds-p0446.md#pdf-p453))
- [ ] **R009** 화면 너비가 충분하지 않을 때 도움 패널은 패널 열기 버튼으로 축약하여 제공한다. ([p.454](../reference/krds-p0446.md#pdf-p454))
- [ ] **R010** 아이콘과 인접 배경 간 명도 대비를 3:1 이상으로 제공한다. ([p.455](../reference/krds-p0446.md#pdf-p455))
- [ ] **R011** 아이콘 버튼에 이름을 제공한다. ([p.455](../reference/krds-p0446.md#pdf-p455))
- [ ] **R012** 아이콘 버튼에 고유하고 적절한 이름을 제공한다. ([p.455](../reference/krds-p0446.md#pdf-p455))
- [ ] **R013** 키보드 초점은 논리적인 순서로 이동해야 한다. ([p.456](../reference/krds-p0446.md#pdf-p456))
- [ ] **R014** 아이콘 버튼의 크기를 44px × 44px 이상으로 제공하는 방안을 고려한다. ([p.456](../reference/krds-p0446.md#pdf-p456))
- [ ] **R015** 패널 열기 버튼과 패널은 본문 바로 다음 요소로 제공한다. ([p.456](../reference/krds-p0446.md#pdf-p456))
