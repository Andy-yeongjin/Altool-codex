# 06. 배지(Badge) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.282-287. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 배지는 비대화형, 요소당 한 개, 짧은 텍스트로 제공하며 주색 배경을 피한다.
- [ ] 색상만으로 의미를 전달하지 않고 배경 대비를 측정한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 레이블은 정확한 내용으로 간결하게 제공한다. ([p.284](../reference/krds-p0282.md#pdf-p284), [p.285](../reference/krds-p0282.md#pdf-p285))
- [ ] **R002** 레이블과 컨테이너의 색상은 일반적인 의미 체계, 일관성을 고려하여 선택한다. ([p.284](../reference/krds-p0282.md#pdf-p284), [p.285](../reference/krds-p0282.md#pdf-p285))
- [ ] **R003** 배지를 대화형 요소로 사용하지 않는다. ([p.284](../reference/krds-p0282.md#pdf-p284), [p.285](../reference/krds-p0282.md#pdf-p285))
- [ ] **R004** 하나의 요소에 한 개의 배지를 사용한다. ([p.284](../reference/krds-p0282.md#pdf-p284), [p.286](../reference/krds-p0282.md#pdf-p286))
- [ ] **R005** 배지의 배경색으로 주조색을 사용하지 않는다. ([p.284](../reference/krds-p0282.md#pdf-p284))
- [ ] **R006** 배지의 배경색으로 서비스의 주색상을 사용하지 않는다. ([p.286](../reference/krds-p0282.md#pdf-p286))
- [ ] **R007** 텍스트 레이블을 제공한다. ([p.287](../reference/krds-p0282.md#pdf-p287))
- [ ] **R008** 텍스트 레이블의 색상은 배경과 4.5:1 이상의 명도 대비를 갖도록 표현한다. ([p.287](../reference/krds-p0282.md#pdf-p287))
