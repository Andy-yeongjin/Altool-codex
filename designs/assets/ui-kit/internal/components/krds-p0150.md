# 01. 건너뛰기 링크(Skip link) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.150-158. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 첫 Tab으로 링크가 보이고 실행 시 스크롤뿐 아니라 대상 초점이 이동하는지 확인한다.
- [ ] 웹 모든 화면, 최대 3개 링크, 유효한 목적지를 확인한다. 네이티브 모바일 앱 예외와 모바일 웹을 혼동하지 않는다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 웹사이트의 모든 화면에 건너뛰기 링크를 제공한다. ([p.153](../reference/krds-p0150.md#pdf-p153), [p.154](../reference/krds-p0150.md#pdf-p154))
- [ ] **R002** 건너뛰기 링크의 개수는 3개 이내로 제공한다. ([p.153](../reference/krds-p0150.md#pdf-p153), [p.154](../reference/krds-p0150.md#pdf-p154))
- [ ] **R003** 건너뛰기 링크 외에 다른 콘텐츠 섹션 탐색 수단을 제공하는 방안을 고려한다. ([p.153](../reference/krds-p0150.md#pdf-p153), [p.155](../reference/krds-p0150.md#pdf-p155))
- [ ] **R004** 건너뛰기 링크의 목적지를 적절하게 설정한다. ([p.153](../reference/krds-p0150.md#pdf-p153), [p.155](../reference/krds-p0150.md#pdf-p155))
- [ ] **R005** 모바일 애플리케이션에서는 건너뛰기 링크를 제공하지 않을 수 있다. ([p.156](../reference/krds-p0150.md#pdf-p156))
- [ ] **R006** 건너뛰기 링크 목록은 문서의 가장 첫 요소로 제공한다. ([p.157](../reference/krds-p0150.md#pdf-p157))
- [ ] **R007** 건너뛰기 링크의 초점이 명확하게 구분되도록 표현한다. ([p.157](../reference/krds-p0150.md#pdf-p157))
- [ ] **R008** 건너뛰기 링크 실행 시 스크롤 동작과 함께 연결된 목적지 섹션으로 Focus 이벤트가 발생해야 한다. ([p.157](../reference/krds-p0150.md#pdf-p157))
