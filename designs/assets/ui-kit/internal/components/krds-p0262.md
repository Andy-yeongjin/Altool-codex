# 04. 디스클로저(Disclosure) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.262-269. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 부가 정보 아래 한 개의 초기 접힘 디스클로저를 두고 버튼으로 펼침·접힘을 조작한다.
- [ ] 상태를 보조기술에 알리고 접힌 콘텐츠로 초점이 들어가지 않는지 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 기본적으로 축소된 상태로 제공한다. ([p.265](../reference/krds-p0262.md#pdf-p265), [p.266](../reference/krds-p0262.md#pdf-p266))
- [ ] **R002** 디스클로저를 통해 제공하고자 하는 부가 정보와 관련된 정보/컨트롤/섹션 아래에 배치한다. ([p.265](../reference/krds-p0262.md#pdf-p265), [p.266](../reference/krds-p0262.md#pdf-p266))
- [ ] **R003** 가능한 한 하나의 섹션에 하나의 디스클로저만 사용한다. ([p.265](../reference/krds-p0262.md#pdf-p265), [p.267](../reference/krds-p0262.md#pdf-p267))
- [ ] **R004** 디스클로저를 버튼 역할로 제공한다. ([p.268](../reference/krds-p0262.md#pdf-p268))
- [ ] **R005** 스크린 리더에서 확장/축소 상태 정보를 확인할 수 있도록 한다. ([p.268](../reference/krds-p0262.md#pdf-p268))
