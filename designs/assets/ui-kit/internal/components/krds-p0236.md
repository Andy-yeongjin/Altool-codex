# 01. 구조화 목록(Structured list) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.236-242. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 같은 분류·순서의 실제 목록 데이터로 도구막대·주요 행동·정렬·필터를 확인한다.
- [ ] 행 클릭과 별도 버튼의 키보드 초점, 빈 목록·로딩·오류·모바일 정보를 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 도구 막대를 구성하는 사용자 인터페이스는 모든 화면에서 일관된 위치에 동일한 순서로 배치한다. ([p.238](../reference/krds-p0236.md#pdf-p238), [p.239](../reference/krds-p0236.md#pdf-p239))
- [ ] **R002** 콜투액션(Call to Action) 은 항목과 관련된 가장 중요한 행동을 유도하기 위해 사용한다. ([p.238](../reference/krds-p0236.md#pdf-p238), [p.239](../reference/krds-p0236.md#pdf-p239))
- [ ] **R003** 사용자가 필요로 하는 기능과 행동 버튼을 제공한다. ([p.238](../reference/krds-p0236.md#pdf-p238), [p.240](../reference/krds-p0236.md#pdf-p240))
- [ ] **R004** 항목의 콘텐츠에는 모든 정보를 일관된 분류 체계와 순서로 제공한다. ([p.238](../reference/krds-p0236.md#pdf-p238), [p.240](../reference/krds-p0236.md#pdf-p240))
- [ ] **R005** 구조화 목록에서 제공되는 모든 기능을 키보드로 실행할 수 있도록 한다. ([p.241](../reference/krds-p0236.md#pdf-p241))
- [ ] **R006** 구조화 목록에서 제공되는 모든 기능에 키보드 초점이 명확하게 표시되도록 한다. ([p.241](../reference/krds-p0236.md#pdf-p241))
- [ ] **R007** 구조화 목록에서 제공되는 모든 기능은 사용자가 예측 가능한 방식으로 작동해야 한다. ([p.241](../reference/krds-p0236.md#pdf-p241))
