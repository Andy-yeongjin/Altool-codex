# 11. 표(Table) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.342-353. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 표 헤딩·셀 관계, 텍스트 좌측/수량 우측 정렬, 비어 있는 값의 대시, 최소 열 너비와 정렬 동작을 확인한다.
- [ ] 모바일 재배열 또는 가로 스크롤에서 데이터 손실이 없는지, 키보드만으로 스크롤 가능한지 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 표는 데이터 잘림 없이 표시될 수 있는 영역에 사용한다. ([p.345](../reference/krds-p0342.md#pdf-p345), [p.346](../reference/krds-p0342.md#pdf-p346))
- [ ] **R002** 열의 최소 너비는 콘텐츠의 길이를 고려하여 설정한다. ([p.345](../reference/krds-p0342.md#pdf-p345), [p.347](../reference/krds-p0342.md#pdf-p347))
- [ ] **R003** 열 구분선의 사용을 지양한다. ([p.345](../reference/krds-p0342.md#pdf-p345), [p.347](../reference/krds-p0342.md#pdf-p347))
- [ ] **R004** 양적 데이터를 전달하기 위한 숫자는 오른쪽으로 정렬한다. ([p.345](../reference/krds-p0342.md#pdf-p345), [p.347](../reference/krds-p0342.md#pdf-p347))
- [ ] **R005** 텍스트 데이터, 명목 데이터는 왼쪽으로 정렬한다. ([p.345](../reference/krds-p0342.md#pdf-p345), [p.348](../reference/krds-p0342.md#pdf-p348))
- [ ] **R006** 열의 개수를 최소화한다. ([p.345](../reference/krds-p0342.md#pdf-p345), [p.348](../reference/krds-p0342.md#pdf-p348))
- [ ] **R007** 사용자가 원하는 대로 데이터를 정렬할 수 있는 기능을 제공한다. ([p.345](../reference/krds-p0342.md#pdf-p345), [p.348](../reference/krds-p0342.md#pdf-p348))
- [ ] **R008** 데이터값이 존재하지 않는 경우 셀을 비워두지 않고 대시(-)를 제공한다. ([p.345](../reference/krds-p0342.md#pdf-p345), [p.349](../reference/krds-p0342.md#pdf-p349))
- [ ] **R009** 화면 너비가 충분하지 않은 경우 데이터의 배열 방식의 변경을 고려한다. ([p.350](../reference/krds-p0342.md#pdf-p350))
- [ ] **R010** 화면 너비가 충분하지 않은 경우 표 영역에 가로 스크롤을 사용하는 방안을 고려한다. ([p.351](../reference/krds-p0342.md#pdf-p351))
- [ ] **R011** 데이터의 구조를 적절하게 반영하여 마크업한다. ([p.352](../reference/krds-p0342.md#pdf-p352))
- [ ] **R012** 가로 스크롤이 필요한 경우 단순한 동작으로 스크롤 위치를 조정할 수 있도록 한다. ([p.352](../reference/krds-p0342.md#pdf-p352))
