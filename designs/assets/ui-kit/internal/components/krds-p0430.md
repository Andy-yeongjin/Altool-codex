# 01. 단계 표시기(Step indicator) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.430-436. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 3~7단계를 논리적 순서목록으로 표시하고 현재 단계의 텍스트·보조기술 상태를 확인한다.
- [ ] 허용되는 단계 이동과 선택 단계 건너뛰기를 실제 데이터 상태와 대조한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 단계 레이블은 해당 프로세스에 대한 간결하고 명확한 내용으로 제공한다. ([p.431](../reference/krds-p0430.md#pdf-p431), [p.432](../reference/krds-p0430.md#pdf-p432))
- [ ] **R002** 단계는 좌에서 우 또는 상에서 하의 순서로 논리적으로 전개될 수 있도록 구성한다. ([p.431](../reference/krds-p0430.md#pdf-p431), [p.433](../reference/krds-p0430.md#pdf-p433))
- [ ] **R003** 단계의 수는 최소 3개에서 최대 7개로 제공한다. ([p.431](../reference/krds-p0430.md#pdf-p431), [p.433](../reference/krds-p0430.md#pdf-p433))
- [ ] **R004** 현재 단계를 명확하게 인지할 수 있도록 표현한다. ([p.431](../reference/krds-p0430.md#pdf-p431), [p.434](../reference/krds-p0430.md#pdf-p434))
- [ ] **R005** 과업의 성격에 적합한 탐색 모델을 제공한다. ([p.431](../reference/krds-p0430.md#pdf-p431), [p.435](../reference/krds-p0430.md#pdf-p435))
- [ ] **R006** 선택적인 단계를 건너뛸 수 있는 수단을 제공한다. ([p.431](../reference/krds-p0430.md#pdf-p431), [p.435](../reference/krds-p0430.md#pdf-p435))
- [ ] **R007** 순서 있는 목록을 사용한다. ([p.436](../reference/krds-p0430.md#pdf-p436))
- [ ] **R008** 단계 식별자를 색상으로만 구분하여 표현하지 않는다. ([p.436](../reference/krds-p0430.md#pdf-p436))
- [ ] **R009** 현재 단계를 스크린 리더로 확인할 수 있도록 한다. ([p.436](../reference/krds-p0430.md#pdf-p436))
