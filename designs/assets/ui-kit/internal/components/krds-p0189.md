# 04. 사이드 메뉴(Side navigation) 적용·검증 카드

출처: 행정안전부 KRDS, 디지털 정부서비스 UI/UX 가이드라인(2024.02), PDF p.189-203. 공공누리 제1유형 출처표시.

이 카드는 Altool이 작성한 적용 절차와 원문의 번호 규칙 색인이다. 원문 전체, 예외·사용 부적합 용례·그림·키보드 표를 대체하지 않는다. 현재 상태: **대상 앱 미검증**.

## 적용 전 판단과 실제 검증

- [ ] 최대 2수준 메뉴, 현재 항목, 펼침·접힘 상태와 접힌 링크의 초점 제외를 확인한다.
- [ ] 모바일에서 사이드 메뉴를 생략하면 메인 메뉴 등으로 같은 탐색이 가능한지 확인한다.
- [ ] 아래 원문 모든 페이지에서 개요·유형·구조·사용성·플랫폼·접근성·상호작용을 읽고, 이 앱에 적용/비적용/예외를 근거와 함께 기록한다.
- [ ] 채택한 실제 화면에서 기본·선택·초점·비활성·로딩·빈·오류·성공 중 적용되는 상태와 키보드·터치·반응형·보조기술을 검증한다. 없는 상태를 자산 수를 늘리기 위해 만들지 않는다.

## 원문 번호 규칙 빠른 점검

번호 제목의 줄바꿈을 합치고 동일 문구만 중복 제거했다. 본문에만 있는 조건과 번호 없는 키보드 상호작용은 아래 전체 원문에서 추가 확인한다.

- [ ] **R001** 현재 탐색 중인 화면에 대한 링크를 강조 표시한다. ([p.194](../reference/krds-p0189.md#pdf-p194), [p.195](../reference/krds-p0189.md#pdf-p195))
- [ ] **R002** 메뉴의 계층 구조는 최대 2개 수준까지 사용한다. ([p.194](../reference/krds-p0189.md#pdf-p194), [p.196](../reference/krds-p0189.md#pdf-p196))
- [ ] **R003** 하위 수준 메뉴 표시에 확장 가능한 영역을 사용하는 방안을 고려한다. ([p.194](../reference/krds-p0189.md#pdf-p194), [p.197](../reference/krds-p0189.md#pdf-p197))
- [ ] **R004** 메뉴의 계층 구조를 명확하게 구분하여 표현한다. ([p.194](../reference/krds-p0189.md#pdf-p194), [p.198](../reference/krds-p0189.md#pdf-p198))
- [ ] **R005** 화면 너비가 충분하지 않은 경우 사이드 메뉴를 표시하지 않는다. ([p.199](../reference/krds-p0189.md#pdf-p199))
- [ ] **R006** 메뉴의 컨테이너가 내비게이션 섹션임을 스크린 리더에서 인지할 수 있도록 한다. ([p.200](../reference/krds-p0189.md#pdf-p200))
- [ ] **R007** 메뉴 링크의 계층 구조를 표현한다. ([p.200](../reference/krds-p0189.md#pdf-p200))
- [ ] **R008** 활성화된 메뉴 정보가 스크린 리더로 전달될 수 있도록 한다. ([p.200](../reference/krds-p0189.md#pdf-p200))
- [ ] **R009** 메뉴 링크는 키보드로 탐색할 수 있도록 한다. ([p.201](../reference/krds-p0189.md#pdf-p201))
- [ ] **R010** 키보드의 초점은 메뉴의 계층 순서대로 이동하도록 한다. ([p.201](../reference/krds-p0189.md#pdf-p201))
- [ ] **R011** 스크린 리더에서 하위 수준 메뉴의 확장/축소 상태를 확인할 수 있도록 한다. ([p.201](../reference/krds-p0189.md#pdf-p201))
- [ ] **R012** 축소된 메뉴 링크에 보조 기술이 접근되지 않도록 제공한다. ([p.202](../reference/krds-p0189.md#pdf-p202))
