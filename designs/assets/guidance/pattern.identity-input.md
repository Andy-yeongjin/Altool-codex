# 개인 식별 정보 입력 — 회사 적용 지침

Altool 기본 회사 계약. 기존 Altool 작성 적용 체크리스트에서 채택한 기본 지침이며 KRDS 인증이나 원문 전체 채택이 아니다. 회사 도입 전 조정 후 자산과 함께 버전 배포한다. 기능/상태에 해당하는 조건만 적용하고 없는 기능을 추가하지 않는다. 상충하는 회사 필수 계약은 공동 변경으로 해결하며 임의 N/A로 면제하지 않는다.

<a id="usage"></a>
## 사용·배치·동작

- G01: 개인 정보가 꼭 필요한지 먼저 확인하고, 각 항목의 수집·활용 목적을 인접 설명으로 알린다.
- G02: 복사·붙여넣기를 막지 않고 실제 값·성별·국가 코드의 기본값을 강제하지 않는다.
- G03: 이름은 단일 필드로 받고 모든 언어·공백·기호·숫자를 허용한다. 짧은 이름이나 긴 이름에 임의의 3~5자 제약을 두지 않는다.
- G04: 개명한 사용자의 이름을 막지 않으며 실제 인증기관에서 제약이 생기면 변경 절차 도움말을 제공한다.
- G05: 생년월일은 달력이나 연도·일 셀렉트 대신 형식을 설명한 텍스트 입력을 쓴다.
- G06: 성별은 기본 선택을 없애고 선택 안 함을 제공한다.
- G07: 목적상 필요하지 않다면 휴대전화만 강요하지 않는다. 전화 유형·각 번호의 레이블을 명확히 한다.
- G08: 공백·하이픈·대시·괄호 전화 형식을 허용한다. 국가명+코드 콤보박스를 제공한다.
- G09: 여러 번호를 받으면 각각 구분하고 주 연락처 선택을 제공한다.
- G10: 개인 식별 입력은 name, bday, tel 등 목적에 맞는 autocomplete를 제공한다.
