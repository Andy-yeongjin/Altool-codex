# 필터링·정렬 — 회사 적용 지침

Altool 기본 회사 계약. 기존 Altool 작성 적용 체크리스트에서 채택한 기본 지침이며 KRDS 인증이나 원문 전체 채택이 아니다. 회사 도입 전 조정 후 자산과 함께 버전 배포한다. 기능/상태에 해당하는 조건만 적용하고 없는 기능을 추가하지 않는다. 상충하는 회사 필수 계약은 공동 변경으로 해결하며 임의 N/A로 면제하지 않는다.

<a id="usage"></a>
## 사용·배치·동작

- G01: 데이터에 맞게 텍스트·스코프·선택·범위·쿼리·관계형 필터를 선택한다. 필요 이상의 옵션을 강제하지 않는다.
- G02: 즉각 표시와 일괄 표시를 처리 속도·조건 수에 맞게 선택한다.
- G03: 수평막대·인라인·사이드패널·모달은 화면공간/과업에 맞게 선택한다.
- G04: 충분한 공간에서는 주요 필터를 숨기지 않고 선택값을 분명히 표현한다.
- G05: 적용 조건·조건 수·결과 수와 개별해제·전체해제를 제공한다.
- G06: 필터·정렬에 간결한 레이블과 그룹헤딩을 제공하고 핵심옵션부터 배치한다.
- G07: 관련 속성은 묶고 관계형 선택의 하위 옵션을 상위 속성과 맞춘다.
- G08: 정렬은 목록 우상단, 인라인 정렬은 열 헤더에 배치한다.
- G09: 실제 메타데이터가 색인화·검색 가능하며 옵션별 결과를 반환하는지 검증한다.
- G10: 날짜/시간은 범위를 입력할 수 있게 하고 3개 이상 속성에는 전체 초기화를 제공한다. 자료의 정밀도에 맞추어 일자·연월·시간 범위를 선택하고 양끝 포함 여부 및 자정 경계를 표시한다. 같은 연월은 해당 월 전체이며 역순 오류 때 입력과 이전 적용 결과를 유지한다.
- G11: 좁은 화면에 축약 컨트롤을 쓴다면 필터→정렬 순서와 접근성을 보존한다.
- G12: 변경된 결과 수는 assertive live region으로 알린다.
- G13: 즉각 갱신 후 선택 컨트롤, 일괄 적용 후 제출 버튼의 초점을 유지한다.
- G14: 인라인 정렬은 키보드/클릭으로 오름·내림을 바꾸며 프로그램적 정렬 상태를 전달한다.
