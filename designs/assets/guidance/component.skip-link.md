# 건너뛰기 링크 — 회사 적용 지침

Altool 기본 회사 계약. 기존 Altool 작성 적용 체크리스트에서 채택한 기본 지침이며 KRDS 인증이나 원문 전체 채택이 아니다. 회사 도입 전 조정 후 자산과 함께 버전 배포한다. 기능/상태에 해당하는 조건만 적용하고 없는 기능을 추가하지 않는다. 상충하는 회사 필수 계약은 공동 변경으로 해결하며 임의 N/A로 면제하지 않는다.

<a id="usage"></a>
## 사용·배치·동작

- G01: 반복 탐색 영역이 있는 화면에 제공한다. 반복 영역이 없는 단일 화면이나 네이티브 앱의 예외를 모든 모바일 웹의 생략 근거로 확대하지 않는다. 대개 본문 1개, 최대 3개로 핵심 목적지를 먼저 둔다. (p.150,154)
- G02: 헤더 앞의 첫 키보드 초점으로 배치하되 쿠키 동의·모달의 선행 초점 조건을 존중한다. 일반 상태에서는 시각적으로 숨기고 키보드 포커스를 받을 때만 화면 상단에 표시한다. 표시는 본문/헤더 배치를 밀지 않는다. 활성화하면 브레드크럼을 제외한 실제 main 본문으로 화면과 초점을 함께 이동한다.
- 기본값 G03: 기본 변형은 focus-only다. visible은 항상 노출하는 별도 요구가 명시된 경우에만 선택한다. 첫 Tab 표시·Enter 본문 초점 이동·초점 이탈 후 숨김을 실제 확인한다.
