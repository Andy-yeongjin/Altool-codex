# 공통 의미 자산 — 회사 적용 지침

회사 도입 전 자산과 함께 조정·배포하는 계약이다. 해당 종류의 항목만 읽는다.

<a id="brand"></a>
## brand

- G01: 회사에서 확정한 CI만 운영에 사용한다. 샘플 표기는 회사 CI 확정으로 간주하지 않으며 공통 릴리스로 교체한다.
- G02: 헤더·푸터에서 실제 운영 주체를 식별할 수 있게 한다. 정부 상징·배너는 일반 회사 CI의 대체물이 아니다.

<a id="foundation"></a>
## foundation

- G01: 선택한 회사 토큰을 공통으로 적용하고 사용자 디자인과 충돌하는 값은 기능별 임의 값이 아닌 공통 계약에서 해결한다.
- G02: 주색·보조색·배경·텍스트·경계·강조·위험/주의/성공/정보 역할을 구분한다. 강조색을 남용하지 않고 상태는 색상 외 문구나 아이콘으로도 전달한다. 60/30/10은 화면별 강제 면적이 아닌 균형을 위한 참고다.
- G03: 기본·호버·누름·비활성 상태의 의미와 대비를 확인한다. 같은 색 계열의 상태 변화가 갑자기 역전되거나 글자를 읽지 못하게 하지 않는다. 팔레트의 모든 조합이 접근성을 만족한다고 가정하지 않는다.
- G04: 실제 텍스트/배경 대비는 기본 4.5:1 이상, 의미 있는 비텍스트 경계·상태 표시는 3:1 이상으로 검증한다. 큰 글자 예외를 쓸 때는 적용 표준의 단위를 확인한다. 원문 p71/77의 px 표기만으로 예외나 인증을 선언하지 않는다.
- G05: 페이지 제목·구역 제목·본문·보조 설명·레이블의 역할을 구분하여 공통 서체 크기·굵기·행간을 사용한다. 사용자 기본 글꼴 확대와 줌을 보존하고 rem 기준을 혼용하지 않는다. 회사 고유 장식 서체는 작은 본문 가독성을 해치지 않게 적용한다.
- G06: 회사에서 승인한 요소별 반경을 적용한다. v27의 컨트롤4px·직각 영역선·원형 상태점은 구분하며 컨테이너 크기에 따라 반경을 자동 확대하지 않는다. 정부 상징 기관에만 해당하는 최대12px 규칙을 일반 회사에 강제하지 않는다.
- G07: 승인된 회사 토큰의 간격을 사용한다. 기본8px/보조4px 척도와 v27 라벨 간격6px 등의 명시적 컴포넌트 규격을 구분하고 앱별 임의값을 추가하지 않는다.

<a id="icon"></a>
## icon

- G01: 의미에 맞는 등록 아이콘을 사용하고 텍스트 레이블 또는 접근 가능한 이름을 제공한다. 방향 조작은 icon.chevron-left/right/up/down의 고정 방향을 선택하며 icon.angle의 방향을 추측하지 않는다. 장식 이미지는 보조기술에서 중복으로 읽히지 않게 한다.
- G02: v27 아이콘은 기본16px·소형14px·강조20px, 선 두께1.5이며 기존24/32/48px 크기도 호환한다. 24×24 viewBox 비율과 그림의 의미를 보존한다. 아이콘 크기와 클릭 가능한 영역 크기는 구분하며 장식 아이콘을 모든 버튼에 강제하지 않는다.
- G03: 같은 역할·크기에서 선 굵기와 선형/채움형을 임의 혼용하지 않는다. 등록된 선택·비활성 등의 변형만 상태와 연결한다. 작은 크기에서도 과도한 장식·생략 없이 의미가 식별되는지 확인한다.
- G04: 새 공통 아이콘이 필요한 경우 회사 팩에서 같은 기준으로 제작한다. 24px 기준 정사각 18×18, 원 20×20, 직사각 16×20/20×16 키라인을 참고하여 시각적 면적·여백·반경을 맞추며 앱별로 다시 그리지 않는다.

<a id="image"></a>
## image

- G01: 이미지 상태와 인접한 텍스트 안내를 일치시키고 필요한 대체 설명을 제공한다.

<a id="message"></a>
## message

- G01: 공통 메시지 key로 문구를 읽고 실제 오류/성공 상태 및 다음 행동과 연결한다. 필드 오류는 해당 입력 가까이에 두고 입력을 보존한다.
