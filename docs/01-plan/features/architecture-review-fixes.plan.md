## 범위

2026-09-07 사용자가 승인한 리뷰 AR-1~9를 수정한다. AR-10 구 PRD 경로는 호환을 위해 보류한다. 헌법/표준/PRD/Spec 책임 구조와 사용자 원본, 기존 작업 트리는 보존한다.

## 성공 기준

- AR-1/9: PyYAML 없는 Python에서도 오프라인 설치·설치 후 게이트가 작동하고, Windows 대화형 실패 안내가 남는다.
- AR-2/7: 구현 단계의 면제 태그와 명시 root 없는 비표준 체크 경로를 거부하되 정상 비UI/legacy 검증은 보존한다.
- AR-5/6: 디자인 탐색·재정규화 조건을 기존 공통 절차로 모으고 하위 HTML/보조 자산/비HTML 변경을 원본 구조 보존 상태로 반영한다.
- AR-3/4: setup 공통 사전검증과 실제 Altool 상태 기준 모드 선택, 기존 AGENTS를 보존하는 AI 진입 안내 보완.
- AR-8: 스타터에 미설치/설치 완료 후속 경로를 안내한다.
- 기존 테스트 및 신규 실패 재현 회귀를 통과하고 UI 변경을 실제 브라우저에서 확인한 뒤 같은 Claude 세션으로 재검수한다. Windows와 실제 네이티브 저장 검증 여부는 별도 표기한다.

## 결정

외부 사내 프로필은 설치형 Python 도구의 요구와 맞지 않아 활성화하지 않는다. 스타터의 흰색 테마는 기존 project-starter Spec을 따른다. 설치용 standards/design.md TBD 템플릿을 제품 화면으로 덮어쓰지 않는다.

PyYAML 6.0.3 순수 Python 원문과 라이선스를 제품 내부에 고정 배포한다. 자체 YAML 파서·시스템 pip 설치·시스템 보호 해제·사용자 가상환경 변경은 하지 않는다. 제품 유지보수 시 라이브러리 업데이트/검증 책임을 갖는다. Python 자체는 여전히 사전 요구사항이다.

승인 범위 AR-1~9 구현 및 기존 Claude 세션 재검수 완료(코드 정합성 ✅ 9, ❌ 0). AR-10은 보류 유지. 시스템 Python의 site-packages 없는 실행으로 66개, Node 11개 테스트가 통과했다. 변경 UI 안내·중첩 파일 선택·미리보기와 가이드 탐색·아코디언·390/1280px 화면을 실제 브라우저에서 확인했다.

네이티브 폴더 권한을 통한 실제 저장, file:// 더블클릭 실행, Windows 설치 실행, AI의 전체 workflow 행동은 미검증이다. 상세 근거와 별도 도구 감사의 미통과 결과는 `reviews/code-review-feedback.md` 최신 확인을 따른다. 이 상태는 배포 검증 완료가 아니다.
