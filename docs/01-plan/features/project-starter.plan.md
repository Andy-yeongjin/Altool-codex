# 프로젝트 스타터 Plan

> 현재 문서 분류·검증 한계: [제품 문서 상태 색인](../../verification-status.md). 아래 과거 기록은 당시 실행 범위이며 최신 Altool 완료 판정을 대신하지 않는다.

상태: Implemented — 브라우저 네이티브 폴더 선택·실제 저장 최종 확인 대기

## 범위와 성공 기준

- 루트 `project-starter.html`을 Altool 프로젝트 스타터로 제공한다. 기존 PRD 작성 폼은 유지하고 기존 PRD 선택·디자인 업로드·프로젝트 폴더 직접 저장을 추가한다.
- ZIP 다운로드가 아닌 사용자가 선택하고 쓰기 권한을 허용한 프로젝트 폴더에 저장한다. PRD는 prd/, 참고는 prd/refs/, Claude 디자인은 designs/claude-design/, 기타 디자인은 designs/, Stitch는 designs/stitch/로 배치한다.
- 흰 바탕, 읽기 쉬운 짙은 글자, 명확한 선택/오류/저장 상태. 데스크톱·모바일 레이아웃을 유지한다.
- 기존 파일 덮어쓰기 확인, 중복 경로·잘못된 파일명·지원하지 않는 브라우저·권한 취소·부분 실패를 명확히 처리한다.
- 설치기와 가이드의 이름·링크를 함께 변경한다. 기존 PRD 및 디자인 원본 내용은 재작성하지 않는다.

## 결정과 영향

제품 준비 도구 한 화면의 변경이다. 설치 프로젝트용 `standards/design.md`는 TBD 배포 템플릿이므로 이 화면의 흰색 테마로 덮어쓰지 않는다. 이번 사용자 디자인 지시를 아래 기능 Spec에서 확정한다. 헌법·프로젝트 표준은 스타터 저장 대상에서 제외한다.

브라우저 File System Access API로 로컬 저장한다. 지원하지 않는 브라우저에는 Chrome/Edge 안내를 표시하며 ZIP이나 서버 전송으로 자동 우회하지 않는다. 브라우저 폴더 선택/권한 UI가 필요한 것은 OS 보안 경계다. 파일과 폴더 권한은 새로고침 후 유지하지 않는다.

검증: 순수 저장 로직 단위 테스트, 기존 Python 회귀, macOS 설치, 실제 브라우저 입력·파일 선택·미리보기·저장·취소·충돌·반응형 확인. 도구가 지원하지 않는 실제 OS 대화상자는 미검증으로 구분한다.
