# 회사 디자인 편집 진입점 통합

> 현재 문서 분류·검증 한계: [제품 문서 상태 색인](../../verification-status.md). 아래 과거 기록은 당시 실행 범위이며 최신 Altool 완료 판정을 대신하지 않는다.

상태: Completed — 검증 기록: docs/03-analysis/features/ui-kit-design-entry.analysis.md

회사마다 외형을 바꿀 때 방대한 UI 구현/참고 자료를 탐색하지 않도록 한다. 현재 외형·동작·자산 의미 ID와 공식 원본 바이트를 보존한다.

- ui-kit/design: 테마와 작성 CSS의 유일한 편집 원천, 수정 안내.
- ui-kit/internal: 기존 구현·참고·검증·생성물. 배포 CSS는 design에서 생성한다.
- 생성기·라우터·등록 정보·미리보기·설치·테스트의 경로를 동기화한다.
- 소스 이동/경로 변환은 기계적으로 수행하고 기존 파일을 파괴하지 않는다. 공식 upstream 내용과 과거 릴리스 해시는 유지한다.
- 생성 재현, CSS 검사, 의미 ID/원본 무결성, 전체 회귀와 실제 대표 화면 확인을 완료 조건으로 한다.
