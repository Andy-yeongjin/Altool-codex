# 공통 UI 소비 계약 보완

> 현재 문서 분류·검증 한계: [제품 문서 상태 색인](../../verification-status.md). 아래 과거 기록은 당시 실행 범위이며 최신 Altool 완료 판정을 대신하지 않는다.

상태: Completed — 요청한 UI 소비 계약 범위 검증 완료

## 목적과 범위

회사 팩을 재사용했어도 CSS 우선순위·방향 의미·모바일 차트 가독성이 달라진 소비 앱 검수 결과를 해결한다. 헌법 지시 수를 늘리지 않는다.

- [x] 회사 CSS의 기본값과 화면 설계값의 우선순위를 로드 순서와 분리한다.
- [x] 원본은 보존하고 파생 어댑터의 미정의 참조·검출된 대비 조합을 수정한다.
- [x] 기존 꺾쇠 원본에서 방향이 고정된 의미 자산을 제공한다.
- [x] 배포 전 CSS 검사와 소비 화면의 실제 측정 검사를 구분하고 재사용 도구·회귀 테스트를 제공한다.
- [x] altool-test의 기존 업무 동작을 보존하며 동일 화면에서 회귀 검증한다.

## 성공 기준

1. adapter 생성 재현·공식 원본 무결성·배포 CSS 변수/대비 검사 통과.
2. 앱 CSS가 공통 CSS 앞/뒤에 있어도 같은 설계값이 적용된다.
3. 좌우 자산이 다른 방향을 표현하고 기존 의미 ID는 유지된다.
4. 데스크톱 섹션 제목21px·첫 viewport 목록 진입부 노출, 모바일 차트 글자 가독성·표 이동을 실제 검증한다.
5. 기존 단위/E2E와 신규 실패 주입 회귀가 통과한다. 이 범위 밖 미검증은 그대로 남긴다.

## 결정

CSS cascade layer로 공통 기본값을 격리한다. 회사 토큰을 앱 임의 테마로 대체할 권한을 부여하는 것은 아니다. 측정 도구는 기존 UI-03 검증을 구체화하며 모든 앱에 대시보드 밀도를 강제하지 않는다. 이번 사례만으로 범용 차트 라이브러리 전체를 추가하지 않는다.
