## 범위

2026-09-08 마무리 작업: PDF 전988페이지를 실제 렌더/원문과 대조하여 재사용 UI·상태·변형·배치/동작 지침의 누락을 보완하고, 제공 변형의 실제 동작 검증 장부를 작성한다. 컴포넌트/기본 패턴/서비스는 앞서 승인한 에이전트 분담을 재개하고 루트는 원칙·스타일·통합 대조와 브라우저 검증을 담당한다. 기존 설치본 마이그레이션은 사용자 요청으로 제외한다. PDF 페이지 검토, 구현 존재, 자동 테스트, 실제 브라우저/보조기술 검증은 독립 상태로 기록하며 미수행을 완료로 생성하지 않는다.

사용자가 요청한 기본 CI·아이콘·상태 이미지·공통 안내 문구를 `designs/assets/`에 제공한다. 규칙은 기존 `standards/design.md`에 두고 목록/파일은 자산 폴더가 소유한다. 자산 카탈로그는 규칙 라우터가 아니다.

## 추가 결정: 회사 내 여러 개발자의 일관성

2026-09-08 도입 모델 확정: Altool은 한 회사의 사내 바이브코딩 도구로 설치한다. 도입 전에 Altool 기본 자산을 회사가 제공한 디자인에 맞춰 조정·검증하고, 그 회사 전용 공통 팩을 사내에 배포한다. 제품 자산 경로는 `designs/assets/ui-kit/internal/`이며 KRDS는 제품 이름이나 별도 선택 테마가 아닌 참고 출처로 보존한다. 이번 변경은 폴더·연결 경로·제품 안내 정리이며 실제 회사 디자인 적용이나 중앙 배포 서버 구축은 포함하지 않는다. 의미 ID·상태 동작·원본 라이선스는 유지하고 새 QA 릴리스에서 경로를 갱신한다.

2026-09-08 사용자 확정: 참고 예제 모음이 아니라 같은 회사의 모든 Altool 프로젝트가 같은 의미에 같은 자산을 쓰는 선제작 공통 팩이다. 재사용 가능한 UI·상태·변형은 제작하고, 실기관·실데이터·백엔드 연결만 프로젝트별 계약으로 남긴다.

- `registry.json`이 의미 ID→기본 자산/허용 변형을 지정한다. `catalog.json`은 원문·비채택 참고까지 검색하는 보조 색인이다. 에이전트는 registry에서 먼저 resolve하고 자산이 없으면 공통 등록 또는 기능 한정 근거를 기록한다.
- 동일 의미의 아이콘·문구를 기능마다 새로 그리거나 하드코딩하지 않는다. 회사 팩 버전·hash를 고정하고 소비 경로·사용 ID·소비 파일 SHA256을 검사한다. 임의 미등록 ID·변형·원본 변조·다른 버전·검증 후 소비 파일 변경은 실패한다. 제작 원본의 `releases.json`에 버전별 lock hash를 보존해 중간 버전을 거쳐도 같은 버전의 다른 내용 재발행을 거부한다.
- CI는 회사가 지정하기 전 Altool 샘플이며 정부 로고/식별자를 회사 CI로 채택하지 않는다. 사용자 디자인은 페이지 구조를 정하되 채택된 회사 의미 자산과 충돌하면 회사 공통 변경 여부를 먼저 확인한다.
- 파일 기반 배포에서 같은 회사는 같은 팩을 배포 원본으로 사용한다. 서로 다른 로컬 복사본의 동시 변경을 자동 합의시키는 중앙 서버를 이 작업에 몰래 추가하지 않는다. 공통 팩 변경은 새 버전 배포와 소비 프로젝트 재검증으로 전파한다.
- 자동 게이트는 등록·원본 무결성·주석을 제외한 인용 참조·검증 당시 소비 파일의 동일성을 검사한다. 인용 문자열의 실제 실행이나 임의 UI의 의미를 완벽히 판별하는 보장은 하지 않으며 의미 누락은 Analyze/Browser에서 독립 대조한다.

2026-09-08 사용자 추가 요청: 제공한 `guides/디지털 정부서비스 UIUX 가이드라인(2024.02).pdf` 988쪽 전체를 기준으로 범위를 확대한다. 37개 컴포넌트, 11개 기본 패턴, 5개 서비스 패턴의 세부 단계, 스타일·원칙·적용 조건을 원문 페이지와 연결한다. 목차/페이지 수집, 재사용 자산 존재, 상호작용 검증, 원문 의미 준수는 서로 다른 완료 상태로 관리한다. 자동 추출이나 공식 코드 복사만으로 전부 구현·검증 완료라고 하지 않는다.

공식 KRDS 키트 1.1.0(commit d6bb184c823e4757f05807ea4646a23e3133b6e6)을 재사용 후보로 고정한다. 이는 2024 PDF와 같은 버전임을 보증하지 않으며 항목별 차이를 기록한다. 공공누리 제1유형 출처 표시를 지키며 폰트/부속 라이브러리의 별도 고지도 보존한다. 정부 상징·공식기관 표시는 일반 프로젝트 CI에 자동 적용하지 않는다. 원문 '피해야 할 사례'는 재사용 추천 자산이 아닌 검증 반례다.

## 성공 기준

- 편집 가능한 원본 SVG CI 3종, 공식 키트 SVG 92종(아이콘91·파비콘1), 상태 이미지 8종과 한국어 문구 JSON을 제공한다. 원문 확장에 따라 자체 이미지 예제 SVG와 패턴 자산도 추가한다.
- CI는 Altool 샘플 브랜드이며 설치 프로젝트의 브랜드로 강제하지 않는다. 기본 자산만으로 디자인 계약 TBD를 완료 처리하지 않는다.
- AI는 기존 자산 재사용, 공통/기능 전용 판단, 출처·사용 조건·실제 배포 경로 연결을 담당한다.
- 설치기는 제품 팩과 기존 회사 팩을 먼저 검증한다. 기존 정상 팩이 있으면 그 릴리스를 보존하며 소스 팩으로 자동 교체하지 않는다. 팩이 없는 설치 대상의 기존 파일과 핀 고정 자산이 충돌하면 자산 배치 전에 실패한다. 나머지 누락 파일만 추가하고 기존 사용자 CI·카탈로그·디자인 계약을 덮어쓰지 않는다. 제품 원본·기존 설치본·사용자 디자인 보존 회귀를 검사한다.
- 독립 실행 가능한 미리보기의 기본 화면은 registry 기반 회사 표준이며 catalog 기반 비채택 참고 자료와 분리한다. 두 범위의 분류·검색·메시지 예시, 회사 표준 ID 복사와 참고 자료 경로/문구 복사를 실제 브라우저로 확인한다. 데스크톱/모바일, 빈 검색, 로딩 실패 안내를 검증한다.

## 적용 경계

상품 데이터·사진·법적 동의문·인증/결제 처리 코드는 만들지 않는다. SVG는 단순 CI·아이콘·UI 상태에 적합한 코드 기반 원본으로 직접 제작한다. 현재 설치용 디자인 템플릿은 TBD를 유지하며, 자산 및 카탈로그 화면의 확정 시각 값만 기능 Spec에 기록한다. 이 작업은 제품 개발이며 Altool 명령 완주 증거를 만들지 않는다.

2026-09-08 문서 동기화: 초기 기록에 남았던 목록 상세 복귀·미디어/고급 검색·다건 신청/내역·정기 간행물 등의 UI 대안은 확장 구현으로 보완되었다. 현재 제공 변형은 각 `variants-manifest.json`, 원문 연결·미검증 경계는 mapping/contracts 및 최신 검증 기록을 기준으로 확인한다. 공통 게이트 결함 H-1~H-4는 `reviews/company-assets-review.md`에서 독립 재검수 승인됐으며, 이 승인을 전체 자산·브라우저 검증 완료로 확대하지 않는다.
