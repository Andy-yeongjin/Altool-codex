# 디자인 실측 완료 게이트와 서버 주소 탐색

> 현재 문서 분류·검증 한계: [제품 문서 상태 색인](../../verification-status.md). 아래 과거 기록은 당시 실행 범위이며 최신 Altool 완료 판정을 대신하지 않는다.

상태: Completed

## 범위

비개발자가 CSS 충돌 재검수를 요청하지 않아도 Spec → Analyze → Browser → 완료 검사에서 기대값과 실제 화면 증거를 연결한다. 기존 디자인 권위·헌법·회사 팩·소비 대시보드는 변경하지 않는다.

- [x] Spec에 출처가 있는 기계 판독 계약을 고정한다.
- [x] Analyze/Fix는 실패·미검증을 명시적으로 기록하고 Browser/oneshot 완료는 실제 재비교 통과를 요구한다.
- [x] 계약·원천·구현 변경, 누락·불일치 관찰을 거부한다.
- [x] 3000/3001 고정 탐색을 제거하고 명시 URL·프로젝트 실행 기록/설정으로 서버를 찾는다.
- [x] 정상/실패 주입·새 설치·전체 회귀를 검증하고 절차와 템플릿을 동기화한다.

## 경계

도구가 원시 관찰의 진실성이나 모든 화면 요구의 완전성을 스스로 증명하지는 못한다. 독립 Analyze의 대상 누락 검토, 실제 브라우저 조작과 시각 확인은 유지한다. 검사기가 브라우저를 대신 조작하거나 사용자 서버를 시작·종료하지 않는다.
