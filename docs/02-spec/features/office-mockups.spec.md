# 사내 공통 자산 조합 목업 5종

제품 유지보수 명세이며 공식 oneshot 완료 증거가 아니다. 검증 해석은 [문서 색인](../../verification-status.md)을 따른다.

## 범위와 원천

순수 oneshot 반복 대신 회사 공통 요소로 사내 페이지 5개를 구성해 디자인과 조합을 검토한다.

- 경비 내역 조회: 필터·날짜·선택 승인·표·상세 대화상자.
- 구매 신청: 폼·필수 오류·날짜·첨부·확인 대화상자.
- 결재 상세: 읽기 전용 상세·승인/반려 확인·이력.
- 예산 현황: 지표·가로 막대·접근 가능한 데이터 표·병렬 섹션.
- 연계 모니터링: 조회·표·로그 대화상자·모의 재처리.

공통 계약은 standards/company-ui.md, 선택 자산의 company guidance 및 internal/company/docs의 BUSINESS-USAGE/PAGE-PATTERNS를 따른다. 현재 배포 버전은 designs/assets/pack.lock.json에서 확인한다. 시작 당시 qa.24를 현재 버전으로 고정하지 않는다.

HTML은 scripts/build-office-mockups.mjs가 생성한다. 목업은 company.css 및 CompanyBusiness/CompanySelect API를 재사용하고, 목업 CSS는 기능별 레이아웃·표 스크롤 폭만 소유한다.

## 확정된 공통 프레임

- 회사명·CI 경로·공통 문의 정보는 ui-kit/design/company.json을 단일 원천으로 사용하고 CompanyBusiness.companyFrame으로 채운다. 회사명을 파일명에서 추론하지 않는다.
- CI는 brand/altool-wordmark-inverse.svg 1종이다. 투명 배경, 연속 녹색 그라데이션(#86EFAC→#22C55E→#15803D) 심볼과 흰색 Altool 글자를 유지하며 어두운 헤더 맨 왼쪽에 127.5×34px로 표시한다. 삭제한 심볼 단독·진한 글자 버전은 복원하지 않는다.
- CI 내용 hash를 이미지 URL에 붙인다. 원본 변경 후 재빌드하면 URL이 바뀌고, 같은 내용이면 유지한다. 소비 페이지는 갱신된 runtime을 로드해야 한다.
- 단일 페이지는 헤더 중심, 다중 페이지는 데스크톱 210px 사이드바를 기본으로 한다. 헤더에는 CI와 업무 시스템 이름을 표시한다.
- 데스크톱 토글은 본문 페이지 제목 왼쪽에 둔다. 공통 menu 아이콘 16px·조작 영역 44px이며 사이드바 숨김/본문 확장과 복원을 수행하고 접근 가능한 이름·aria-expanded를 갱신한다.
- 760px 이하에서는 본문 토글을 숨기고 헤더 우측에 44px 햄버거 트리거를 둔다. 메뉴는 기본 접힘, Escape/바깥 클릭으로 닫힘, 현재 페이지 강조를 제공한다. CompanyBusiness.responsiveNavigation이 메뉴 DOM 하나를 이동시킨다.
- 모바일 목록은 연회색 #F1F3F5 배경·옅은 공통 테두리·헤더 아래 6px 간격으로 표시한다. 그림자는 공통 브랜드 토큰을 사용하며 기본값은 `0 8px 20px rgba(24,51,79,.56)`이다. 진한 외곽선·가로 메뉴·헤더 제목 앞 데스크톱 토글 시안은 채택하지 않는다.
- 푸터는 본문 열 하단에 얇은 구분선과 회사명·문의 정보·안내 동작을 표시한다. 화면에 고정하지 않고 짧은 콘텐츠에서는 하단으로 밀며 모바일은 세로 배치한다. CI·제작 버전을 반복하지 않는다.
- 목업 연락처는 isExample=true로 예시임을 표시한다. 실제 안내/문의 URL이 없는 목업만 시연 콜백을 제공하고, 운영 앱에서 URL·콜백이 모두 없으면 해당 동작을 숨긴다.

## 목업 전용 범위와 검증

승인/접수는 메모리 시연이며 새로고침 시 초기화한다. 서버 저장·DB·실제 인증·금융 처리는 범위 밖이다. 가상 데이터와 문구는 실제 처리로 오인되지 않게 표시한다.

고정 시연 일자는 2026-09-11이며 조회 시작일은 이 일자와 비교한다. 실제 업무 내역별 날짜 조회를 검증하는 앱이 아니다. 핑크·초록·노랑 페이지는 팔레트 비교용이며 공통 기본 파란색을 변경하지 않는다. 밝은 팔레트의 채움·글자·포커스 분리 계약과 제한 범위 검증은 company-palette 명세·분석을 따른다.

공통 설정·배포 일치는 tests/test_responsive_navigation.py, 실제 조작·시각 관찰은 [목업 분석](../../03-analysis/features/office-mockups.analysis.md)에 기록한다. 필터·상태 전환·모달·대표 신청 및 데스크톱/모바일 넘침을 검증하고, 파일 첨부 네이티브 선택 여부는 별도 표시한다. 과거 관찰을 최신 전체 UI 또는 oneshot 통과로 환산하지 않는다.
