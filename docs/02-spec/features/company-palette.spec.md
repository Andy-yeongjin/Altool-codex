# 회사 팔레트 단일 설정

검증 상태와 문서 분류는 [문서 색인](../../verification-status.md)을 따른다.

요청: 회사 브랜드 색을 공통에서 설정하여 모든 브랜드 표현에 연결한다. 현재 파란 디자인은 변경하지 않는다.

- 원본은 ui-kit/design/theme.css 상단의 회사 브랜드 팔레트 블록. company.json은 회사명/CI/연락처만 소유한다.
- 컴포넌트의 주색·hover·active·선택·포커스·헤더·차트·메뉴 그림자는 역할 토큰으로 연결한다. 기존 primary/secondary 토큰과 컴포넌트별 별칭은 유지한다.
- 오류/경고/성공/진행 상태색과 CI는 브랜드 팔레트로 자동 치환하지 않는다. 중립 회색도 유지한다.
- 밝은 주색은 primary(채움)와 foreground(링크·지표·현재 날짜 글자), focus(포커스 외곽선)를 분리한다. 기본 foreground는 primary, focus는 foreground를 참조하여 기존 파란색을 보존한다. 노랑 시안은 채움 #F2C94C를 유지하고 foreground/focus를 #806012로 지정한다. 체크 선택 표시도 foreground를 사용한다. 글자는 실제 배경 대비 4.5:1, 포커스는 인접 밝은 배경 대비 3:1 이상을 검사한다. 반전 헤더의 흰색 포커스는 유지한다.
- 현재 색상을 보존하고 기본 색 실측 전후 비교, 구조 검사, 대표 UI 조작, 격리된 분홍 팔레트 검증 페이지에서 브랜드 표현 전파/상태색 불변을 확인한다. 분홍 시안은 기본값으로 배포하지 않는다.
- 지침의 기본 파란색 수치는 팔레트 참조로 정정하고 수정 진입점/빌드 절차를 안내한다.
