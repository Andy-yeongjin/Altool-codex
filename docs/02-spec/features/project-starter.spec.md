# 프로젝트 스타터 Spec

> 현재 문서 분류·검증 한계: [제품 문서 상태 색인](../../verification-status.md). 아래 과거 기록은 당시 실행 범위이며 최신 Altool 완료 판정을 대신하지 않는다.

상태: Implemented — 브라우저 네이티브 폴더 선택·실제 저장 최종 확인 대기

## 화면과 계약

1. 상단: 이름, 로컬 처리 안내, 대상 프로젝트 폴더 선택과 선택 상태.
2. PRD: 기존 Markdown/TXT 선택 또는 기존 작성 폼. 원본 MD는 그대로 저장하고 TXT는 AI가 읽을 수 있도록 확장자만 .md로 저장한다. PDF/DOCX 등은 참고자료로 별도 첨부한다. 디자인만 준비할 때는 PRD 생략 모드를 제공한다.
3. 디자인: Claude HTML·보조 파일 / 일반 디자인 / Stitch 파일·폴더 구분. 선택 목록에 실제 저장 상대 경로와 삭제 버튼을 표시한다. 압축 업로드는 받지 않고 먼저 풀도록 안내한다.
4. 검토: PRD 본문(텍스트로만 렌더링), 전체 저장 경로, 프로젝트명, 저장 버튼. 브라우저 권한 및 기존 파일 확인 뒤 저장. 완료 시 경로 목록과 후속 안내: 미설치 프로젝트는 배포 설치기→`$altool setup`, 설치·초기 확인 완료 프로젝트는 oneshot으로 개발 요청.

## 저장 계약

- 외부 CDN·업로드 서버 없이 로컬 파일 API를 사용한다. File System Access 미지원이면 명확한 안내와 저장 비활성화. 읽기/선택만으로 쓰지 않는다.
- 원본 파일 bytes를 보존한다. 폴더 입력은 선택 폴더 이름만 제거하고 하위 상대 경로를 유지한다. 경로 탈출·Windows 예약 이름·대소문자/Unicode 정규화 충돌·중복 출력 경로는 저장 전 거부한다.
- 모든 충돌을 쓰기 전에 수집하고 명시적 확인 후에만 덮어쓴다. 디렉터리와 파일의 충돌은 실패로 표시한다. 개별 파일 close가 끝난 것만 성공 목록에 기록한다. 전체 파일 집합의 원자적 저장을 주장하지 않으며 실패 시 완료 경로와 실패 원인을 남긴다.
- 기존 PRD 선택은 작성 폼 값과 병합하지 않는다. 모드 전환은 입력을 유지하되 선택된 모드의 자산만 저장한다. 미리보기 후 입력 변경이 있을 수 없도록 native dialog를 사용한다.
- 참고자료 코멘트가 있으면 prd/refs/asset-notes.md에 저장한다. 이 이름과 사용자가 선택한 파일이 충돌해도 조용히 덮어쓰지 않고 중복 경로 오류로 표시한다.
- 사용자 업로드 HTML은 실행·iframe 미리보기하지 않고 파일명·경로만 보여준다. 코멘트는 textContent/escaping 처리한다.

## 디자인 및 표준 적용

사용자 요청인 흰색 테마와 기존 폼 구조를 원천으로 한다. 배경 #ffffff, 보조 면 #f5f7fa, 본문 #17212f, 설명 #526174, 경계 #cbd3dd, 주요 액션 #1859b7 및 흰 글자. 시스템 폰트, 컨트롤 최소 44px, 820px 본문 폭, 모바일 단일 열, 모달 포커스 복귀·Escape 닫기, 저장 상태 live region을 적용한다. 이 결정은 스타터 한 화면에만 적용하며 설치 프로젝트의 디자인 기본값으로 승격하지 않는다.

| 원천 | 적용 | 검증 |
| --- | --- | --- |
| 사용자 흰색 테마·직접 저장 요청 | 스타터 UI·폴더 쓰기 흐름 | 브라우저 조작·저장 결과 |
| 헌법 보안·품질·추적 원칙 | 경로 제한·원본 보존·실패 보고 | 저장 로직 단위 테스트 |

## API 근거

[Chrome File System Access 문서](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access) 및 [MDN showDirectoryPicker](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker): 사용자 제스처에서 폴더 선택/쓰기 권한 요청 후 FileSystemDirectoryHandle 및 createWritable 사용. 실제 지원 여부는 런타임 기능 검사한다.
