2026-09-11 사용자 승인. 제품 qa.10과 현재 백업 test3에 적용했다. 중지된 순수 test3에는 적용하지 않았다.

- 인앱 http://127.0.0.1:3000/ 실제 확인: 기업 목록 h2가 table보다 위, 연도·단위 설명 표시, caption clip=inset(50%)/폭1px. 매출 정렬→다음 페이지로2/3 확인. 2024년 선택 시 설명도2024년으로 변경됨.
