## 승인 범위와 계약
test4에서 승인한 배치를 공통 팩 qa.17에 반영한다. 왼쪽 summary는 선택 건수와 하단 안내, 오른쪽 actions는 보조·주요 버튼 순서다. 600px 이하에서는 세로 배치하고 버튼을 오른쪽 정렬한다. 집계·일괄 처리 API와 기존 소비 마크업은 유지한다. 새 조합 클래스·공통 예제·BUSINESS-USAGE 및 V27-S02 하위 지침을 함께 변경했다.

- 공통 제작기: CSS 변수·대비 사전 검사 통과.
- test_table_toolbar.py: 3개 통과.

- REQ-0092 선택→반려 확인창→취소 확인.
