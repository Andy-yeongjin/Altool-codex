# 공통 팔레트 정리 검증

검증 상태와 문서 분류는 [문서 색인](../../verification-status.md)을 따른다.

## 변경

### 밝은 팔레트 후속 보완 · 2026-09-11

- 채움(primary), 밝은 바탕의 글자·선택 표시(foreground), 포커스(focus)를 분리했다. 기본 연결은 기존 파란색을 유지하며 CI·상태색은 변경하지 않았다.
- 노랑 시안: 버튼 배경 rgb(242,201,76), 글자 rgb(48,39,16), 키보드 Tab으로 이동한 select 트리거의 focus-visible 외곽선 rgb(128,96,18), 달력 오늘 날짜 글자 rgb(128,96,18)를 인앱에서 실측했다. 날짜 선택 동작 및 390px 포커스 표시를 확인했다.
- 기본 시안 1280px: 버튼·포커스 rgb(21,84,160), 헤더 rgb(24,51,79) 유지 확인. 노랑 시안은 공통 기본값으로 승격하지 않는다.
- tests/test_company_palette.py는 흰색/연회색 3종 배경에서 foreground 4.5:1·focus 3:1 이상, 노랑 버튼 글자 4.5:1 이상을 검사한다. 전체 Python 215개 통과, 생성물 일치·팩 qa.38 검사 통과.
- 이번 실브라우저 검증은 대표 입력·달력·기본 테마 범위다. 모든 컴포넌트/배경 조합과 footer hover의 실제 포인터 관찰은 전수 검증하지 않았으므로 전체 접근성 인증으로 해석하지 않는다.

- theme.css 상단 COMPANY BRAND PALETTE에 주색·hover·active·전경·선택/hover 배경·헤더·그림자 및 기존 primary/secondary 단계 팔레트를 모았다. 기존 토큰 이름은 호환 별칭으로 보존했다.
- components.css의 브랜드 파란색/남색 하드코딩은 역할 변수로 대체했다. 오류·경고·성공·진행과 중립색은 독립값을 유지한다. CI는 수정하지 않았다.
- 편집 README, COMPANY-04, V27-P01과 Spec을 동기화했다. 분홍 예시는 배포 기본값이 아니라 tests/fixtures/company-palette.html 안에서만 작동한다.

## 검증

- company-palette 단위 검사 2건, data-top-border 1건, section-group 5건 통과.
- 제작 --check, 배포 CSS 변수/명시적 대비 검사, 자산 validate, standards validate, diff 공백 검사 통과. 대비 검사는 명시적 142쌍/추론 불가 80규칙이며 전체 UI 대비 검증을 뜻하지 않는다.
- 인앱 동일 경비 화면 전후: 헤더 rgb(24,51,79), 주요 버튼·현재 메뉴·섹션 선 rgb(21,84,160) 모두 동일.
- 격리 화면 실제 전환 버튼 클릭: 버튼/선택/섹션 선/차트가 rgb(165,43,97), 헤더 rgb(68,38,56)로 전파. 다시 클릭 복원 확인.
- 상태점 성공 rgb(36,100,63), 오류 rgb(162,36,44), 진행 rgb(21,84,160)와 삭제 버튼 rgb(162,36,44)는 브랜드 전환 전후 동일.
- 390px 격리 화면 가로 넘침 없음. 실제 경비 모바일 메뉴 열기/닫기, 기존 헤더색과 56% 그림자 유지 확인. 1280px 사이드바 접기/복원·조회 클릭 확인.

## 범위

기본 디자인은 파란색 그대로다. 다른 회사 팔레트의 모든 색상 조합/상태 대비는 해당 팔레트 확정 후 별도 검증해야 한다. 전체 업무/모든 브라우저 상태 회귀 완료를 주장하지 않는다.
