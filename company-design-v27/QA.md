DOM 계약 검사는 경량 테스트 하네스를 사용합니다. 브라우저 DOM·레이아웃·접근성 트리를 재현하지 않습니다.
첨부 검사의 DataTransfer도 테스트 대역이며, 실제 FileList·폼 전송은 사용 브라우저에서 확인해야 합니다.

## 재현 방법

```sh
python3 scripts/build_design.py
python3 scripts/build_business_preview.py
python3 scripts/check_release.py
```

패키지 생성 과정에서는 CSS 변수·괄호·원본 보존·빌드 재현성·ZIP 무결성도 별도 확인했습니다.
관련 원본 비교는 제작 워크스페이스의 최초 입력 파일을 사용하므로 배포 ZIP의 check_release.py에 포함하지 않습니다.

## 실제 앱에서 남은 확인

- Pretendard 로딩과 대체 폰트. ZIP에는 폰트 파일이 없습니다.
- 기본·hover·focus·disabled·readonly·오류·빈 결과·로딩 상태.
- 긴 한글·큰 숫자·320px 폭·200% 확대와 가로 조회조건 줄바꿈.
- 팝업 위치와 잘림, Tab/Enter/Space/Esc 이동, 닫은 뒤 포커스 복귀, 스크린리더 안내.
- 실제 파일 선택·여러 번 추가·개별 해제·초기화·취소와 FormData의 파일 목록.
- 파일 업로드 정책·서버 검증·권한·인증·DB/API·멱등성·실제 저장.
- 기존 앱 CSS와 함께 적용했을 때의 우선순위·레이어 충돌.

공통 예제의 조회·신청·재처리·인증 안내는 샘플 동작입니다. 서버 연결 또는 업무 검증 완료로 간주하지 않습니다.
Popover 미지원 환경의 fixed 대체 경로는 조상 transform/overflow 영향을 받을 수 있습니다.
첨부는 DataTransfer와 input.files 할당을 지원하는 브라우저가 필요합니다.
